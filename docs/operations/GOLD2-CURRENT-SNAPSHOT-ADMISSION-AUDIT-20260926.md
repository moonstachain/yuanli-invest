# GOLD2 当前截面与执行准入独立审查

2026-09-26 独立检查 strategy、live snapshot、daily request，以及登记/网关重算。只使用合成回归和已保存的真实公有研究证据；没有伪造实际 08:30，没有真实账户或订单操作。

已修复三项明确缺口：

1. 原 DEFERRED 费用限制只在 current snapshot 包裹层生效。现在共享信号计算也把 `DEFERRED_TO_EXECUTION_GATE` 作为执行硬门；即使下游错误地把结构占位费用的 grade 升为 CONSERVATIVE，历史 strict replay 与 current replay 都保持 `actionable_entry=false`，不生成计划费用或保证金数字。
2. 原网关和登记用历史逐日 strict 入口重算，完整新 current signal 因元数据/回看信息集不同永远不匹配。现在共用 `replay_frozen_signal`：只有用途精确匹配、明确费用政策、准确08:30、当前官方 session、无当日日线，且整个当前数据集没有未来取得/发布或宏观观测输入时，才使用 current replay；其余数据保留历史 strict 语义。独立时间锚、签名、账户身份与实际成本核对等原门不变。
3. 上期所原文现在必须含有与 manifest 日期一致的 `report_date`，原文不能仅更换清单日期而被当作此前日线。未知或错误类型的 execution_mode 也稳定失败关闭。
