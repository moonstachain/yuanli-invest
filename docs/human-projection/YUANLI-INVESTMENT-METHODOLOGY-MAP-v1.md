## 00｜这张地图是什么

原力投研不是一套“选股技巧”，也不是一个单一因子模型。它更接近一个 Investment Research Intelligence Operating System：把哲学、研究语法、收益机制、可证伪 Thesis、资本表达、Point-in-Time 记忆、Replay、Benchmark 与 Reality Settlement 编译为可以被人理解、也可以被机器调用的研究体系。

它的主链不是：

```text
Ticker → Opinion → Buy/Sell
```

而是：

```text
Reality → Belief → Return Engine → EngineThesis → Price Semantics
→ Position Expression → Survival Constraint → Settlement → Revision
```

因此，原力投研首先要求研究者回答“这一次究竟准备赚什么钱”，而不是直接回答“这个资产好不好”。

### 本页的角色

本页是 Human Projection / Navigation Map，不是新的 Canon。它把已有正本串起来：

```text
YIP0 负责哲学
```

`Roadmap visibility != Stage authorization`。

## 01｜哲学本源：我们如何认识投资世界

YIP0 的哲学身份是：

> **Fallibilist Reflexive Evolutionary Realism｜可错的反身演化实在论**

它可以压缩成六个词：

> **实在 · 可错 · 反身 · 演化 · 凸性 · 生存**

### 1. 实在｜Reality over Belief

世界不会因为市场相信什么就自动变成什么。Narrative 可以影响资本、价格、融资与行为，但 Reality 仍拥有最终结算权。

核心边界：

```text
Reality != Belief
```

### 2. 可错｜All investment knowledge is provisional

任何观点都只是暂时假说。真正专业的投资判断必须允许被现实推翻，因此一个合格 Thesis 至少需要：

```text
Mechanism + Evidence + Counter-Evidence + Falsifier + Revision Rule
```

### 3. 反身｜Price is both sensor and participant

价格不仅反映现实，也可能改变现实：上涨可以降低融资成本、强化信念、吸引人才和资本；下跌也可能反向破坏信用、融资与经营行为。

所以市场可出现：

```text
Reality → Belief → Capital → Price → Incentives / Financing → Later Reality
```

### 4. 演化｜Becoming before Being

研究的重点不是静态地问“现在是什么”，而是识别：

```text
State_t → State_t+1
```

产业、制度、资本结构、叙事和估值都在演化。

### 5. 凸性｜Few large outcomes dominate

长期财富分布不是线性的。少数极端正确往往远比大量小正确重要，因此系统必须同时研究概率、payoff、path、liquidity 与 survival。

### 6. 生存｜Survival first

任何单次判断都不值得牺牲未来所有判断。原力投研的目标不是最大化某一笔交易，而是最大化长期可持续复利：

```text
Survive → Capture → Compound
```

## 02｜人类语法：势·信·极｜真·价·生

OS vNext 为研究者提供一套稳定的 Human Grammar：

> **势 · 信 · 极｜真 · 价 · 生**
>
> **顺大势 · 乘共识 · 押极值｜凭真据 · 买好价 · 永不死**

它回答六类研究问题：

| 维度 | 问题 |
|---|---|
| P｜势 | 现实世界正在往哪里运动？ |
| N｜信 | 市场正在为哪个未来付钱？ |
| X｜极 | 哪里存在结构性不对称？ |
| E｜真 | 证据够不够，权威到哪一层？ |
| V｜价 | 当前价格已经预付了多少未来？ |
| S｜生 | 如果错了，是否还保有未来复利权？ |

### Human Grammar != Machine Ontology

这是 YIM0 最重要的边界之一。

`势 / 信 / 极｜真 / 价 / 生` 是人类研究导航语法；它帮助研究者观察世界、提出问题、组织证据。它不等于 ME0 的 Return Engine Ontology。

P/N/E/V/S 可以被不同 Engine 的 Thesis 复用。它们是研究 primitive / service，不由某一个 Engine 永久占有。

## 03｜收益机制：C / R / X

ME0 冻结的 Genesis Engine Set 是：

```text
ENG-C｜Compounding
ENG-R｜Reflexive Repricing
ENG-X｜Convexity
```

它们是当前被接受的 Genesis Engine Set，并不声称已经证明覆盖一切可能收益机制；Engine Registry 仍是 open-world。

### ENG-C｜Compounding

核心问题：

> 预期收益的主要来源，是否来自持续的经济价值创造、高回报率再投资、owner-relevant cash flow 增长与时间复利，并且当前价格仍然可接受？

典型机制链：

```text
Value Pool
→ Value Capture
→ ROIC
→ Reinvestment
→ Owner-Relevant Cash Flow
→ Intrinsic Value Compounding
```

稳定问题：

> **我今天为未来现金流付了多少钱？**

ENG-C 不等于“好公司”“龙头”“有护城河”“长期看好”。如果主要收益来自短期 multiple expansion 或预期重定价，那不是纯粹的 C Thesis。

### ENG-R｜Reflexive Repricing

核心问题：

> 在有限时间窗口内，belief、capital flow、price、positioning 与 later reality 是否正在形成自我强化或自我破坏的 repricing loop？

可观察链：

```text
Reality Change / Earnings Realization
↔ Narrative / Expectations
↔ Capital Flow / Positioning
↔ Price / Leadership / Breadth
```

稳定问题：

> **市场正在如何重新定价？什么会让反馈循环断裂？**

ENG-R 不等于任何价格上涨，也不等于没有机制解释的 generic momentum。

### ENG-X｜Convexity

核心问题：

> 预期 portfolio payoff 是否主要由被刻意设计的不对称 / 非线性 payoff structure 决定，其中 tail activation 与 expression geometry 主导结果？

核心结构：

```text
Bounded / Engineered Left Tail
+
Open / Nonlinear Right Tail
```

稳定问题：

> **这份凸性现在卖多少钱？**

ENG-X 不等于“空间大”“高成长”“垄断”“网络效应”。这些可能是其他机制的组成部分，但不能自动创造 X 身份。

### Asset != Engine

资产类别、ticker 或 instrument 本身不拥有永久 Engine identity。

同一个资产可以在不同时间、不同机制和不同 horizon 下承载多个独立 Thesis；真正的 Engine identity 属于 `EngineThesis`。

## 04｜机器对象：Target → Thesis → Passport → Book

ME1 将旧式“一资产一个 ResearchState”的思维重构为：

```text
ResearchTarget
    → EngineThesis [0..N]
        → PositionPassport [0..N]
            → BookState@PIT
```

### ResearchTarget｜它是谁

ResearchTarget 只负责研究对象 identity。它不直接拥有唯一 Engine、唯一投资结论、仓位或 Book 身份。

### EngineThesis｜为什么赚钱

EngineThesis 回答：

> **这一次，我究竟准备赚什么钱？**

每一个 Thesis 只有一个 primary Engine，并有自己的 horizon、mechanism、evidence、counter-evidence、falsifiers、price semantics 与 lifecycle。

### PositionPassport｜如何表达

PositionPassport 是 capital-expression contract，而不是资本授权。它描述允许怎样表达一个已经明确的 Thesis，包括 entry / hold / trim / exit / risk / max-loss / falsifier response 等表达逻辑。

`Research pass != Capital pass`。

### BookState@PIT｜资本逻辑在哪一本账

Book membership 属于 PositionPassport，而不是 ticker。

因此同一个 NVIDIA Target 可以同时存在一个 C Passport 进入 BOOK-C，以及一个 R Passport 进入 BOOK-R，而不是把“NVIDIA”永久贴成某一种资产身份。

### Target != Thesis != Position != Book

这是 ME1 的核心分离：

```text
Identity != Belief != Capital Expression != Book Membership
```

### No Silent Thesis Migration

当原有 R Thesis 被证伪时，不能为了继续持有而在原地把它改写成 C Thesis。

正确处理是：

```text
old EngineThesis → invalidated / closed / settled
new mechanism → new EngineThesis identity
```

这就是 **No Silent Thesis Migration**。

## 05｜研究学习环：PIT / Evidence / Falsifier / Settlement

原力投研的学习不是“写完研报”，而是：

```text
Theory
→ Hypothesis
→ Capability
→ Runtime
→ Replay
→ Benchmark
→ Failure
→ Settlement
→ Revision
```

### Point-in-Time｜当时究竟知道什么

Replay 必须区分：

```text
recorded_at
known_as_of
knowledge_cutoff
replay_cutoff
```

今天已经知道的结果不能倒灌回过去，冒充当时就已拥有的知识。

### Evidence｜结论不能比证据更确定

系统不变量：

```text
ClaimAuthority <= EvidenceAuthority
```

二手证据不能被包装成一手事实；理论名人或模型声望也不能替资产级事实背书。

### Falsifier｜什么事实会让我错

没有 falsifier 的观点更接近信仰，而不是可学习的 Thesis。

### Settlement｜现实最终裁决

Settlement 评价历史，但不重写历史。一个 Thesis 可以被现实结算为：

```text
supported
partially_supported
falsified
indeterminate
```

系统应该保留当时的 Thesis、证据与知识边界，再让现实完成结算，而不是事后改写“我当时其实是另一个逻辑”。

## 06｜五资产案例：同一语法，不同物理

> 以下案例仅用于解释 ontology / state-model 的使用方式，不构成当前投资结论、目标价、alpha claim、组合建议或交易指令。

### NVIDIA｜同一 Target，多条独立 Thesis

**C Thesis 示例**：AI 计算价值池增长 → 系统级价值捕获 → 高 ROIC → 再投资 → owner cash flow 复利。

**R Thesis 示例**：AI 叙事扩散 → hyperscaler capex 上调 → earnings surprise / EPS revision → capital flow → leadership confirmation → repricing loop。

关键点不是“NVDA 属于 C 还是 R”，而是同一 ResearchTarget 可以同时承载不同 EngineThesis，各自有独立机制与 falsifier。

### Gold｜黄金

Gold 没有企业式再投资现金流，因此不能因为“长期重要”就自动成为 C。

它可以出现 R Thesis，例如储备结构、实际利率、财政/货币信用、央行购金与资本流共同推动 repricing；也可以通过特定 instrument 构造 X Thesis，用有限 premium 获取极端货币/地缘尾部的非线性收益。

### UST30Y｜30 年美债

UST30Y 可以承载 R Thesis：通胀路径、政策利率、term premium 与 positioning 共同驱动 duration repricing。

在特定衍生品表达下，也可能出现 X Thesis，但是否属于 X 取决于 payoff geometry，而不是“债券具有防御性”这一标签。

### Copper｜铜

Copper 很适合展示 Reality 与 Belief 的分离：

```text
Reality：电网 / AI data center / electrification / mine supply / grade decline
Belief：市场如何叙述“AI = 铜需求超级周期”
```

研究重点是 Reality change、Narrative diffusion 与 price-implied future 是否出现错配，而不是先验贴上固定 Engine 标签。

### USDJPY｜美元兑日元

USDJPY 常适合研究 R：利差、carry incentives、capital flow、Fed/BOJ 预期、positioning 与汇率之间形成反馈。

真正关键的是 loop 与 loop breaker：一旦政策路径或拥挤仓位反转，反身机制可能迅速反向。

## 09｜十分钟使用方法

面对一个新资产，可以按下面顺序快速进入原力投研：

### 第 1 问｜世界发生了什么真实变化？

先看 P / Reality，不从价格倒推故事。

### 第 2 问｜市场正在相信什么？

拆开 N / Belief，识别共识、预期与叙事扩散。

### 第 3 问｜Reality 与 Belief 最大的差在哪里？

寻找需要被验证、被反驳或可能被重新定价的 gap。

### 第 4 问｜这一次究竟准备赚什么钱？

明确 primary Engine：C、R 或 X；如果说不清楚，就不急着进入 capital expression。

### 第 5 问｜真正的因果机制是什么？

禁止“因为会涨所以会涨”的循环解释。

### 第 6 问｜证据是什么，什么会证明我错？

同时写 supporting evidence、counter-evidence 与 falsifier。

### 第 7 问｜现在的价格要求未来发生什么？

用 Price-Implied Expectations 约束梦想：

```text
Great Future != Great Investment
```

### 第 8 问｜如何表达这个 Thesis？

研究的是 Thesis 的表达，不是 ticker 的永久身份。

### 第 9 问｜如果完全错了，我是否还有下一次？

所有策略最终服从 Survival First。

### 第 10 问｜现实最终怎样结算？

保留 PIT 历史，Replay、Benchmark、Settlement，再把失败编译成 Revision。
