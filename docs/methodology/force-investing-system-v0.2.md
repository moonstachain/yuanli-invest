# 原力投研黄金三角 / PNX-S Framework v0.2

## 0. 定位

本文件把原力投研从 `P × N × X` 的 Candidate 方法论，升级为一套可证伪的综合投资研究框架：

- **P｜Paradigm**：现实世界是否正在发生结构性迁移；
- **N｜Narrative**：群体共识如何形成、加速、拥挤、反转与残留；
- **X｜Extreme Convexity**：财富为何集中于少数右尾，以及如何研究极值激活与收益凸性；
- **E｜Evidence**：所有判断的证据地基；
- **V｜Valuation**：为未来可选性支付的价格，不是第四顶点；
- **S｜Survival**：组合层面的生存与长期几何增长约束，不是第四顶点。

传播口径仍保留：

> **顺大势 · 乘共识 · 押极值。**

但研究口径升级为：

> **现实决定可能性；共识决定价格路径；分布决定财富归属；生存决定能否得到结果。**

`Force = P × N × X` 继续只表达乘法门槛的哲学关系，禁止未经校准的黑箱总分。

---

## 1. 第一性分解

一笔长期投资至少包含四个不可约问题：

1. **Reality**：世界是不是真的发生了结构变化？
2. **Belief**：市场什么时候开始相信、拥挤或遗忘？
3. **Distribution / Payoff**：若判断成立，价值为什么会不成比例地流向少数资产；若通过特定价格与工具表达，收益结构是否非对称？
4. **Survival**：即使前三个判断错误，资本是否仍保有继续复利的资格？

因此：

```text
Reality ──> Belief ──> Distribution / Payoff
   P           N                 X

Evidence E underwrites all claims
Valuation V prices optionality
Survival S constrains the whole system
```

黄金三角不是多因子表。P/N/X 研究三个不同认识论对象；E/V/S 是跨层约束。

---

## 2. P｜Paradigm：方向，不负责择时

### 2.1 第一问题

> 某项技术、产业或制度变化，是否正在从局部创新升级为新的生产函数、基础设施或组织范式？

P 的理论血缘来自 Schumpeter 的创新与创造性破坏、Dosi 的 technological paradigms / trajectories、Freeman/Perez 的技术革命与金融资本阶段框架。

### 2.2 六个观察面

1. `technology_breakthrough`：关键能力是否跨越可用阈值；
2. `cost_curve`：单位成本是否持续下降并打开新需求；
3. `infrastructure`：算力、能源、网络、供应链等是否形成；
4. `capital_formation`：资本开支与融资是否从试验转向系统建设；
5. `institutional_adaptation`：标准、监管、组织与商业制度是否适配；
6. `productivity_diffusion`：是否从演示进入跨行业生产率/单位经济改善。

### 2.3 状态语言

`emergence → installation → frenzy → turning_point → deployment → maturity → unknown`

P 不预测固定康波年份，不允许用“约 50–60 年周期”推算拐点。

### 2.4 目标输出

当前仍以 state + confidence + evidence + counterevidence + falsifier 为主；后续可研究 `stage posterior`，但不得用伪精确概率掩盖样本不足。

---

## 3. N｜Narrative：时点，不等于真相

### 3.1 第一问题

> 同一个现实事实，市场参与者何时开始以相似语言理解、传播并据此行动？

N 的理论血缘包括：

- Kermack–McKendrick：传播动力学；
- information cascades：理性个体也可能形成模仿与瀑布；
- Soros reflexivity：认知影响行动，行动反过来改变现实；
- Shiller Narrative Economics：流行叙事的传播、突变与宏观/市场影响。

### 3.2 状态

`discover → accelerate → consensus → decay → residual → unknown`

### 3.3 观测

- attention / source diversity；
- cohort diffusion；
- `ΔN` narrative velocity；
- `Δ²N` narrative acceleration；
- crowding；
- reverse narrative；
- reflexive feedback；
- novelty / residual persistence。

### 3.4 纪律

- 当前热度 `I(t)` 不等于最终影响；
- 传播力不证明商业真实性；
- 价格可以反向提升叙事传播率；
- 共识很强但边际新增信徒下降时，Narrative Alpha 可能已经衰减。

---

## 4. X｜Extreme Convexity：从单一 Profile 升级为三层极值引擎

X 不再把“公司左尾生存”和“组合生存”混成一个概念。v0.2 把 X 拆为：

### Xs｜Structural Right Tail

> 为什么在范式兑现时，价值可能极端集中于这个实体？

核心结构：

- winner-take-most；
- network effects；
- increasing returns / scale economics；
- bottleneck control；
- switching cost / ecosystem lock-in；
- platform optionality；
- TAM expansion；
- reinvestment runway；
- value capture。

Xs 不是“好公司评分”，而是未来进入财富创造右尾的结构假说。

### Xa｜Tail Activation

> 哪些当前状态会改变未来进入极端结果的条件概率？

分为：

- `Xa_long`：3–10 年超级赢家结构是否持续强化；
- `Xa_event`：数日—数月的极端上涨/下跌概率是否被激活。

原则：

`predictive leading factor ≠ identified causal mechanism`。

允许 EVT、POT/GPD、conditional quantile、regime model、rare-event classification、causal candidate graph 等作为工具；禁止宣称精确预测“黑天鹅”。

### Xp｜Payoff Convexity

> 给定当前价格、工具与期限，这个机会是否呈现有利的非线性 payoff？

研究：

- upside openness；
- downside boundedness；
- optionality；
- instrument convexity；
- valuation embedded expectations；
- cost / premium / path dependency。

“理论上最多亏小、可能赚很多”不是充分条件；必须考虑价格、隐含波动率、时间价值和交易成本。

## 5. E｜Evidence：不是一块装饰地基

P/N/X/V/S 的任何 material claim 必须可追溯至 Evidence Object。

至少区分：

- `fact`：来源直接支持；
- `estimate`：来源或确定性计算得到；
- `inference`：多个事实按公开规则推出；
- `hypothesis`：等待未来验证。

每项重大判断至少需要：

`source + locator + timestamp + provenance + confidence + counterevidence + falsifier + revision`。

基本面属于 Evidence/Fundamental Gate：收入、FCF、ROIC、订单、客户采用、资产负债表、治理等用于证实或证伪，不新增第四顶点。

---

## 6. V｜Valuation：Strike Price，不是第四角

伟大资产不等于伟大投资。

v0.2 将估值定义为：

> **Price of Optionality / Strike Price：为未来右尾可能性支付的当前价格。**

P 决定未来世界可能多大；Xs 决定公司可能捕获多少；Xa 决定极值概率如何变化；Xp 描述收益几何；V 检查这些乐观假设是否已被价格预付。

V 应描述：

- current valuation；
- historical / peer context；
- reverse-DCF embedded growth；
- embedded margin / share assumptions；
- narrative premium；
- expectation gap。

禁止将 V 简化成单一“便宜/贵”分数后直接与 P/N/X 相乘。

---

## 7. S｜Survival：组合外环，不是公司属性

### 7.1 第一问题

> 即使 P/N/X 全部判断错误，投资者是否仍保有继续参与下一轮复利的资格？

S 的理论血缘主要来自：

- Roy Safety First：先控制跌破灾难阈值的概率；
- Kelly：重复下注下最大化长期对数/几何增长；
- Breiman / Thorp：有利游戏、仓位与 Kelly 实践；
- Merton：动态多资产组合与连续时间财富配置；
- disaster-risk / tail-risk literature：低概率巨大损失对资产价格与生存的影响。

### 7.2 S 与公司生存严格分离

- **Issuer / Thesis Durability**：公司现金、债务、再融资、稀释、监管、技术替代等；属于资产研究层。
- **Portfolio Survival**：仓位、相关性、杠杆、流动性、Expected Shortfall、Ruin Probability、Kelly fraction 等；属于组合层。

因此旧 `SurvivalGate` 的公司级语义将在后续 M1.2 合同层重命名/拆分；M1.1 只冻结理论，不改变现有 Schema。

### 7.3 目标函数

概念上：

`maximize long-term geometric wealth subject to survival constraints`。

S 不是“少亏钱”，而是：

> **Never risk the right to compound.**

## 9. 不可机械化成总分

禁止：

`0.3P + 0.3N + 0.4X`

也禁止：

`P × N × X × F × V × Macro = score`

目标是 **gated probabilistic decision system**：

`Evidence → P Gate → Structural Tail Gate → Narrative State → Tail Activation → Valuation/Payoff → Issuer Durability → Portfolio Survival → Replay/Eval`。

关键链不闭合时必须保留 `unknown`。

---

## 10. 科学地位

PNX-S 当前定义为：

> **Integrative Investment Framework / 综合投资决策框架**

而不是被证明的资产定价定理。

它是否具有真实增量，必须通过 point-in-time Replay、held-out evaluation 和 Future Settlement 验证。

核心科学问题：

`P(Future Top Tail | PNX) > P(Future Top Tail | Baseline) ?`

以及：

`Does adding V and S improve geometric wealth and reduce ruin without destroying right-tail capture?`

若不能通过上述检验，理论必须允许被降级、拆解或拒绝。

## 12. 总纲

> **P 看世界，N 看人心，X 看赔率，S 管命。**

更严格地说：

- P 决定 `Direction`；
- N 提供 `Timing / Belief State`；
- X 研究 `Distribution / Payoff`；
- V 定义 `Price Paid`；
- S 约束 `Sizing / Survival`；
- E 负责让所有判断可审计、可证伪、可更新。

原力投研的目标不是持续正确，而是：

> **在不失去继续复利资格的前提下，提高一生捕获少数财富极值的概率。**
