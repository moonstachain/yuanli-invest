# Gold Replay｜AI · ChatGPT 扩散 / 算力基础设施 · 2023

- Case ID: `FT-GR-AI-2023`
- T0: `2023-02-01`
- Status: `pre_registered_reconstruction`
- Primary subject: AI compute infrastructure / NVIDIA ecosystem
- Narrative bridge: `narrative-compute`
- Purpose: 检验在 ChatGPT 叙事早期加速阶段，P 与 X 是否能独立于后来的 AI 狂热被识别。

## 为什么 T0 不是 2022-11-30

2022-11-30 是产品发布 T0，但当日尚不能使用之后约两个月的用户扩散事实。为了检验“叙事已被真实采用数据点燃”这一状态，本案例把研究 T0 预注册为 2023-02-01；只允许使用该日及以前公开可得信息。

## T0 允许信息

- Transformer 与大模型技术在 T0 前已经公开的能力与成本事实；
- ChatGPT 从发布到 T0 的公开采用/访问数据；
- NVIDIA/CUDA、数据中心、GPU 生态在 T0 前已公开的产品与经营信息；
- hyperscaler 在 T0 前已经公开的 AI / cloud capex 与产品动作；
- 当时存在的“AI 新电力”“生成式 AI”等传播载体。

## 明确禁止

- 2023-02-01 之后的 NVIDIA 财报爆发；
- 2024–2026 的 hyperscaler capex、循环交易、OpenAI/Anthropic 后续估值；
- DeepSeek、SaaSpocalypse、2026 AI bubble 搜索热度；
- 后来形成的 AI 赢家名单与指数权重；
- 使用后续价格上涨证明 T0 的 P/N/X。

## 待重建 P/N/X 假说

### P｜Paradigm Potential

待检验假说：`installation`。

重点问题：生成式 AI 是否已经显示出跨任务通用性与成本下降路径，但基础设施、制度、商业模式与生产率扩散仍处早期。

### N｜Narrative Momentum

待检验假说：`accelerate`。

需确认用户采用、媒体/企业传播、融资与产品跟进是否构成跨载体扩散，而不是单一新品短脉冲。

### X｜Extreme Convexity

待检验假说：`convex`，但必须独立审计。

重点：

- CUDA/软件生态与 GPU 供给是否构成瓶颈控制；
- 规模经济、开发者生态和技术路线能否形成持续 value capture；
- 客户集中、周期性、竞争替代、供应链和估值错配是否造成左尾脆弱；
- “AI 范式扩大”与“NVIDIA 能长期捕获价值”必须分别证明。

### Force classification

预注册候选：`golden_extreme`，但若 Fundamental Gate 或 Survival Gate 在 T0 只能 `partial`，最终分类不得强行升高；允许保持 `unknown` / `medium research priority`。

## Falsifiers

- 若 T0 前采用主要来自免费试用，缺少可扩张需求，则 P/N 均需降置信度；
- 若 GPU 瓶颈可快速被替代，CUDA 锁定弱，则 X 下调；
- 若资本开支增长没有后续收入/生产率传导，则“范式强→资产强”链条被证伪；
- 若叙事加速但价格先于经营极端透支，则不能把 N 强自动转换为 Fundamental Gate passed。

## Outcome 窗口

市场：20 / 60 / 120 / 250 日；经营：随后至少两个报告期；结构：算力供需、单位成本、开发者生态、客户集中和资本开支兑现作为长期扩展观察。

## Gold 标准

这个案例成功的标准不是“事后证明 NVIDIA 是赢家”，而是检验 2023-02-01 的点时证据能否独立回答：**AI 是否正在成为结构范式，叙事是否正在加速，以及算力瓶颈的价值捕获是否真实属于该实体。**
