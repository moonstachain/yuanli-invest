# Gold Replay｜Mobile Internet · App Store · 2008

- Case ID: `FT-GR-MOBILE-2008`
- T0: `2008-07-10`
- Status: `pre_registered_reconstruction`
- Primary subject: Apple mobile platform / App Store ecosystem
- Purpose: 检验当范式、叙事与价值捕获结构可能同时改善时，黄金三角能否在后见之明之前识别这种结构。

## T0 允许信息

只允许 2008-07-10 当日及之前：

- 2007 iPhone 发布后已公开的产品采用与行业反应；
- App Store 上线时已经公开的开发者、分发和商业规则；
- 3G/移动网络、触屏设备和智能手机竞争格局；
- Apple 当时已披露的经营、现金流与硬件生态事实；
- “mobile first / software on mobile” 等当时可验证叙事载体。

## 明确禁止

- Facebook 2012–2013 移动广告兑现；
- 后续十多年 iPhone 销量、服务收入与市值；
- 任何后来形成的“移动互联网没有典型大崩盘”结论；
- 用后来赢家名单倒推 2008 年的 X。

## 待重建 P/N/X 假说

### P｜Paradigm Potential

待检验假说：`installation` 向 `deployment` 过渡。

关键审计：设备、网络、开发者工具和分发基础设施是否已经形成互相强化的系统，而不仅是单一爆款硬件。

### N｜Narrative Momentum

待检验假说：`accelerate`。

需要点时验证：App Store 是否形成新的可传播故事与开发者/消费者扩散，而不是只依靠 iPhone 发布的旧热度。

### X｜Extreme Convexity

待检验假说：`convex`。

重点审计：

- 硬件 + OS + 分发 + 开发者生态是否形成控制点；
- 网络效应是否能被平台捕获；
- 现金流与资产负债表是否支持长期验证；
- 平台是否能持续生成新的 optionality，而不是一次性设备利润。

### Force classification

预注册候选：`golden_extreme`；只有在 P/N/X 与 Fundamental/Survival Gate 的 T0 证据同时成立时才允许使用。任何一项证据不足则降为 `unknown` 或较低研究优先级。

## Falsifiers

- App Store 若没有形成可扩张开发者/用户双边生态，则 X 的平台性被证伪；
- 移动网络与设备成本若不足以支持大众采用，则 P 不得进入 deployment；
- 若 Apple 价值捕获仅来自硬件单品、平台抽成与生态锁定无法形成，则 X 下调；
- 若叙事传播只是发布事件短脉冲而非跨载体持续扩散，则 N 不得标 accelerate。

## Outcome 窗口

市场：20 / 60 / 120 / 250 日；经营：随后至少两个报告期；结构：开发者生态、移动流量、平台收入与竞争格局作为长期扩展观察。

## Gold 标准

这个案例成功的标准不是“证明 Apple 后来涨了很多”，而是判断 2008 年点时证据是否已经支持：**移动互联网正在从设备创新变成可持续的平台型生产与分发结构。**
