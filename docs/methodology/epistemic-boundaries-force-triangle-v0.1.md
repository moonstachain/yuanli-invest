# 原力投研黄金三角｜认识论边界 v0.1

## 1. 三层科学地位

| 层 | 可做 | 不可做 |
|---|---|---|
| 范式层 P | 用历史结构组织证据、构建情景、识别 installation / deployment 等阶段性质 | 预测康波固定周期长度、给出拐点年份、用少数历史样本声称统计定律 |
| 叙事层 N | 用可复算代理指标观察传播、拥挤、反向叙事、衰减 | 把词频当因果、把传播力当真实性、把当前热度当最终市场规模 |
| 极值层 X | 描述右尾价值捕获结构与左尾生存风险，使用 EVT 等工具做局部风险测量 | 声称尾部事件可被精确点预测、把 VaR/ES 当成完整极值理论、忽略模型外风险 |

## 2. 历史类比纪律

历史案例用于：

- 暴露机制；
- 构造反事实；
- 形成 falsifier；
- 检查一个规则是否只在单一时代有效。

历史案例不得用于：

- “这次一定和 1999 一样”；
- “AI 必然复制 iPhone”；
- 以结果已知的历史故事反向挑选当时不可知指标；
- 忽略存活者偏差、指数成分变更与会计口径变化。

任何 Replay 必须冻结 `t0`、`point_in_time_rule` 与 `lookahead_check`。

## 3. 叙事因果边界

Shiller 式叙事框架能够解释“故事如何传播并影响行为”的机制，但本仓不把叙事与资产价格的相关性自动解释为单向因果。允许的表述等级：

- `fact`：来源直接支持；
- `inference`：由多个事实按公开规则推出；
- `hypothesis`：等待未来验证。

叙事可能导致价格变化，价格也可能反向提高叙事传播率；二者可以形成反身性回路。研究对象必须保留反向因果与共同原因的可能性。

## 4. 极值边界

X 研究的是分布形状和生存约束，不是“寻找必涨十倍股”。

必须分开：

- **right_tail_capture**：对象能否在范式成立时获得非比例价值；
- **left_tail_survival**：对象在错误、延迟和波动下能否仍保持验证资格。

不能仅因“理论上有巨大 TAM”判定右尾强；需要价值捕获链证据。不能仅因短期波动低判定左尾安全；需要融资、杠杆、稀释、监管和技术替代证据。

## 5. 基本面与估值边界

基本面是 Gate，不是第四顶点。估值是 Context，不是黄金三角内部的第四分数。

原因：若把所有研究维度都变成顶点，模型会退化成不可证伪的综合评分器。当前 v0.1 强制保留：

`P/N/X → Fundamental Gate → Survival Gate → Research Priority`

而不是：

`P × N × X × F × V × Macro × ... = single score`

## 6. 评分禁令

在完成独立历史校准和未来结算前，禁止：

- 将 P/N/X 统一映射到 0–100 后直接相乘；
- 为了得到想要的排名手工调整权重；
- 把缺失数据填成中性分；
- 将 `unknown` 强行转成低分或高分；
- 根据未来结果回改 T0 规则。

`ScoreSnapshot` 当前仅用于研究优先级的可审计输出，不能成为自动买卖器。

## 7. 治理边界

- 方法论 Candidate 可以进入 `docs/methodology`；
- 研究对象在 Evidence Reviewer 未指派前不得升级为 `approved`；
- Governance Registry 激活与 A9 operational canon 切换是独立 Human Gate；
- `yuanli-invest-rsi` 是实验沙箱，任何黄金三角变更进入该仓时只可作为 challenger，不自动修改 FROZEN；
- Outcome 只能生成 `LearningCandidate`，不得自动回写方法论。

## 8. v0.1 的成功标准

本版本不以收益率证明自己。成功标准是：

1. 同一历史时点的不同研究者按相同证据能得到相近 P/N/X 状态；
2. 框架能够显式区分“范式正确”与“资产正确”；
3. 能记录并解释失败案例，而不是只收集赢家；
4. Replay 可以复算且通过 lookahead 检查；
5. 后续未来结算能够判断黄金三角是否真的提升研究校准，而非只提升叙事美感。
