# 叙事投研方法手册

版本：1.0.0
适用：A 股 AI 主线、全球产业映射、3–18 个月
用途：研究流程、数据字典、证据台账、回放与周报模板
边界：研究优先级不等于交易建议或可投准入

## 1. 操作总则

每项研究按 `CTX → EVD → DEC → WPK → ACT → OUT → LRN` 运行：定义上下文，收集点时证据，形成可证伪判断，生成研究工作包，执行只读分析，输出分层结论，最后把新证据、权重偏差和被证伪假说回流。

四条硬规则：

1. 先定义叙事边界，再搜索数据；
2. 先建立产业传导链，再加入公司；
3. 先写证伪条件，再看价格表现；
4. 任何没有来源、时间戳或可复算输入的结果标记 `partial`。

输出语言分四类：

- `事实`：原始来源可定位；
- `推断`：由多个事实按公开规则推出；
- `假说`：等待未来证据验证；
- `mock`：用于界面或流程演示，不进入研究结论。

## 2. 研究流程

### Step 0：登记研究任务

最小字段：`research_id`、题目、市场、周期、决策对象、明确排除项、研究截止时间、负责人、计算版本。任务必须写出“不回答什么”。

### Step 1：创建 Narrative

定义主叙事、同义词、排除词、相邻叙事和最早可验证起点。示例：“低成本推理促进 AI 应用”不等于“所有 AI 软件”；排除仅在名称中出现 AI、没有产品或经营连接的公司。

### Step 2：登记 T0 与反向 T0

T0 必须是首次可验证催化，如论文、产品、财报、监管文件。行情大涨日只能作为市场事件，不得反推为产业 T0。另登记反向事件：澄清、推迟、降价、客户流失、临床失败。

### Step 3：采集 Observation 与 Evidence

原文先入 Evidence，再把数字和文本特征拆为 Observation。每条观测保存 `event_time` 与 `ingested_at`，避免后来修订的数据回填历史。

### Step 4：建立 AssetMapping

按“叙事→产业节点→产品/BOM→客户/订单→公司收入利润”填写每条边。最弱边决定映射等级。没有公司级证据的对象只进入产业观察池。

### Step 5：生成 StageSnapshot

阶段只能由固定规则生成。输入缺失时返回 `unknown/partial`，不能让研究员手选一个看似合理的阶段。

### Step 6：创建 Thesis/Falsifier

每条 thesis 至少一个确认指标、一个反向指标、一个截止日期。到期未验证则 `expired`，不无限延长。

### Step 7：市场与经营双回放

市场回放观察 20/60/120/250 日；经营回放观察随后两个财报期。价格上涨、盈利预测上调、订单增加和利润兑现分别记录。

### Step 8：研究优先级与下一节点

优先级回答“下一单位研究资源投向哪里”。它不输出买卖方向。每个对象必须显示下一次可验证日期和待取证字段。

## 4. 指标字典

所有指标的公共字段为：定义、公式、单位、方向、窗口、原始来源、去重、缺失策略、更新频率、计算版本、适用市场和证伪条件。

### 4.1 叙事层

| 指标 | 定义/公式 | 单位与方向 | 窗口 | 缺失与证伪 |
|---|---|---|---|---|
| 声量占比 | 叙事去重载体数/全 AI 叙事去重载体数 | ratio；高表示注意力份额高 | 1/7/28d | 覆盖变化需重标；不能直接解释价值 |
| 扩散速度 | 声量占比一阶变化，按时间差标准化 | pct point/day | 7/28d | 低基数单列；平台扩容需断点处理 |
| `R_t` | 新增独立载体/期初活跃载体 | ratio | 7/28d | 不是流行病学因果；报告去重前后 N |
| 载体多样性 | 载体类型分布的归一化熵 | 0–1；高表示跨群体 | 7/28d | 单平台不计算或降置信度 |
| 观点分歧 | 支持/反对/不确定分布熵或模型概率 | 0–1 | 7/28d | 需人工抽样，讽刺和引用易误判 |
| 信息新颖度 | 与过去 90 日语义中心的距离，扣除转载 | 0–1 | event/7d | 新术语不等于新事实；无原文则缺失 |
| 衰减率 | 峰值后半衰期或对数斜率 | day / slope | 28/90d | 新催化出现需分段，不延续旧峰 |
| 原始源占比 | 原始文件/全部去重传播节点 | ratio | 7/28d | 低值提示二手转载占主导 |

#### `R_t` 实施细则

载体身份键：`normalized_actor + canonical_domain + account_id`。内容键：清洗正文后 MinHash/embedding 聚类。引用边：显式链接、引号、相同图片/表格和发布时间。新增载体必须在历史冷却期内未出现；冷却期默认 90 日，可按叙事调整。

`R_t` 不能单独决定阶段。若 `R_t` 上升但新颖度为零，状态可能是机械转载；若载体多样性低，可能是单一营销活动；若反对意见同步上升，扩散不等于共识。

### 4.2 产业兑现层

| 指标 | 定义 | 单位/方向 | 窗口 | 关键证伪 |
|---|---|---|---|---|
| 产品节点成熟度 | 论文/原型/送样/定点/小批/量产/规模收入 | ordinal 0–6 | event | 阶段回退、延迟 |
| 订单验证 | 合同、预付款、订单能见度的证据等级 | S–D | quarter | 客户取消、口径不明 |
| 出货验证 | 原始出货/装机/激活数据 | unit / yoy | month/quarter | 渠道库存而非终端销量 |
| 资本开支传导 | 全球客户 capex→节点需求弹性 | ratio | quarter/year | capex投向与节点不匹配 |
| 收入传导 | 相关收入/总收入及增速 | ratio/yoy | quarter | 公司不披露、混入旧业务 |
| 利润传导 | 相关业务毛利/增量利润 | amount/margin | quarter | 收入增而毛利下降 |
| BOM价值占比 | 单机本公司产品价值/整机BOM | ratio | product gen | 降本、自研、规格切换 |
| 瓶颈稀缺性 | 认证期、良率、产能利用、替代数的组合 | low/med/high | month/quarter | 新产能、替代路线 |
| 替代风险 | 技术、供应商、客户自制替代概率 | low/med/high | event | 路线变化即重评 |

### 4.3 市场反身性层

| 指标 | 定义 | 单位 | 窗口 | 注意 |
|---|---|---|---|---|
| 叙事—价格同步 | 叙事变化与价格/成交的滚动相关与 lead-lag | correlation | 20/60d | 相关不等于因果 |
| 估值分位 | 当前 PE/PS/EV相对自身和行业历史 | percentile | 3/5y | 亏损公司选择合适口径 |
| 成交拥挤 | 换手、成交额占比、涨停集中和横截面相关 | z-score | 5/20d | 市场制度变化需重标 |
| 资金/持仓 | 北向、ETF、基金重仓等点时变化 | amount/ratio | day/quarter | 披露滞后必须保留 event_time |
| 叙事—基本面缺口 | 叙事/估值分位与基本面验证等级差 | ordinal | snapshot | 不作为机械做空信号 |
| 反身通道 | 再融资、招聘、capex、预付款是否因价格/共识改变 | evidence state | event | 无通道证据只报同步 |

### 4.4 证伪与风险层

| 指标 | 定义 | 输出 |
|---|---|---|
| 失败条件覆盖率 | 已登记 falsifier / 必需 falsifier | ratio |
| 催化集中度 | 最大单一催化贡献/全部预期催化 | ratio |
| 证据新鲜度 | 当前时间-最新核心证据时间 | days |
| 证据独立度 | 独立来源组/来源 URL | ratio |
| 数据缺失率 | 必填观测缺失/必填总数 | ratio |
| 结论置信度 | 覆盖、等级、独立性、稳定性组合 | 0–1，非成功概率 |
| 排名稳定性 | 权重扰动后 top-k 重合与名次相关 | Jaccard/Spearman |

## 5. 阶段规则

阶段名固定为：启蒙、加速、共识、衰减；另有 `unknown` 和 `re-acceleration`。

### 启蒙

至少一个 S/A 原始催化；声量占比仍低于历史 50 分位；新颖度高；基本面通常只有产品或试验节点。失败条件：催化被撤回、证据为伪、边界无法定义。

### 加速

7 日 `R_t` 与扩散速度均高于各自历史 75 分位，载体多样性连续两窗上升，且至少出现第二独立原始源。只满足声量增长不够。

### 共识

声量占比高于 85 分位；企业/机构/开发者多类型进入；观点分歧下降或核心因果链趋同；市场拥挤明显。共识不自动代表看多，必须显示估值与基本面缺口。

### 衰减

`R_t`、新颖度和载体多样性至少两项连续下降，或关键证伪事件发生。单纯价格下跌不是叙事衰减；价格下跌但讨论继续扩散可能是争议/反身阶段。

### 再加速

旧叙事在衰减后由新的 S/A 催化重新扩散，必须新建 narrative version 或 episode，不能把两次周期连成一个峰。

## 6. 证据操作规范

### 6.1 等级

- S：监管、交易所、财报、合同可核验信息、原始经营/产品数据；
- A：同行评审论文、权威统计与机构；
- B：头部行业研究，需记录方法和利益关系；
- C：一般媒体、聚合行情；
- D：营销、自述和未核验 AI 摘要。

公司产品发布属于原始产品事实，可为 S；对未来销量的自我预测不自动成为 S 级结论。券商转述公司交流不能替代交易所披露。

### 6.2 三源规则

核心判断至少三组独立来源，至少一组 S/A。三家媒体转同一新闻稿只算一组。学术论文与作者公司的新闻稿若使用同一数据，应标为相关来源。

### 6.3 时间纪律

保存 `published_at`、`effective_at`、`event_time`、`ingested_at`。回放只允许读取当时已发布的版本。同一财报后续更正时，原版本与更正版本都保留。

### 6.4 利益立场

来源标记 regulator、issuer、vendor、sell-side、media、academic、data_aggregator。利益立场不直接降低等级，但影响置信度和独立性判断。

## 7. 缺失值策略

缺失不是零，也不是中性。分三类：

- 随机缺失：短暂抓取失败，可延迟计算；
- 结构缺失：公司不披露相关收入，输出 unknown 并降低映射等级；
- 选择性缺失：只披露有利指标，登记为风险信号。

核心输入缺失率超过 20%，StageSnapshot 最高置信度为 0.6；超过 40%，不得进入排序。任何插补同时保存原始缺失标记和插补版本。

## 8. 研究优先级，不做黑箱总分

页面主视图并列显示五项，不直接显示“9.4”：

1. 阶段/扩散：例如“加速，7日 `R_t=1.42`，多样性上升”；
2. 基本面：例如“B2：送样已验证，订单未验证”；
3. 估值/拥挤：例如“估值 92 分位，成交拥挤高”；
4. 研究优先级：例如“高，因映射不确定且下一节点临近”；
5. 下一节点：例如“2026-Q3 财报相关收入拆分”。

若内部需要排序：先执行证据门，再分别计算 `narrative_priority`、`realization_priority`、`risk_flag`。风险不得用低分与收益信号相抵。权重组至少保存等权、专家权重和数据驱动三版。

## 14. 历史与实时 QA

### 每日自动检查

- JSON schema 与必填字段；
- 时间戳不晚于快照 as-of；
- source URL 与 locator 非空；
- S/A 数字是否存在原始定位；
- 相同原始源是否被重复计数；
- 计算版本是否可解析；
- 冻结输入 hash 是否匹配；
- 缺失率与陈旧证据告警。

### 每周人工检查

- 每个核心结论至少三独立源；
- 抽样复算 5%，S 级关键数全查；
- 新叙事边界是否吞并相邻主题；
- 至少一条相反 thesis 是否仍有效；
- 下一验证日期是否逾期；
- 页面语言是否把优先级误写为投资判断。

### 每季模型检查

- 权重 ±20% 扰动和 top-k 稳定性；
- 滚动样本外 IC/预测修正解释力；
- 按阶段、市场环境和产业时滞分层；
- 幸存者、前视、重叠事件和数据供应商断点；
- 与主题、动量、注意力和基本面基线的增量比较。

## 15. 最终准入与停止条件

以下任何一项成立，保持 `partial` 或停止：

- 核心数字无法追到原始披露；
- 公司映射只有营销、自述或名称相似；
- T0、标的池或估值使用未来信息；
- 结论只靠价格上涨验证；
- 权重轻微变化导致方向翻转；
- 关键反证被删除或截止日期无限延后；
- 公开证据不足却试图升级为可投准入。

研究系统的成功标准不是“预测了多少上涨”，而是能否在同一冻结信息集上回答：当时知道什么、为什么形成该判断、哪条证据改变了状态、结论如何被确认或推翻。
