# 原力投研黄金三角 v0.1

## 0. 一句话

**顺大势 · 乘共识 · 押极值。**

原力投研把一个研究机会拆成三个相互独立、又必须联合审视的维度：

- **P｜Paradigm Potential · 范式势能**：世界正在向哪里发生结构性迁移？
- **N｜Narrative Momentum · 叙事动能**：群体共识正在如何形成、加速、拥挤与衰减？
- **X｜Extreme Convexity · 极值凸性**：若判断成立，价值捕获是否具有非线性右尾；若判断错误，左尾是否仍可生存？

黄金三角追求的不是“高分资产”，而是识别**范式级右尾资产候选**：站在长期结构变化上、处于有利共识扩散位置、且拥有非线性价值捕获可能性的研究对象。

> `Force = P × N × X` 只表达**乘法门槛的哲学关系**，当前版本禁止将三个维度未经校准地压缩成一个伪精确总分。

## 1. 为什么是三角，而不是又一个多因子模型

三个顶点研究的是三个不同问题：

| 顶点 | 研究对象 | 第一问题 | 主要时间尺度 | 研究用途 |
|---|---|---|---|---|
| P | 技术—经济结构 | 世界往哪里迁移？ | 年—十年 | 赛道、结构久期、研究优先级 |
| N | 群体认知传播 | 共识如何形成与衰减？ | 天—年 | 阶段、拥挤、催化与失效窗口 |
| X | 收益与生存分布 | 少数赢家能多大、失败会多坏？ | 事件—多年 | 标的筛选、赔率研究、脆弱性识别 |

因此本框架不是“三个周期模型”，而是：

**历史结构 × 群体传播 × 概率分布。**

现有叙事投研流程继续保留 `CTX → EVD → DEC → WPK → ACT → OUT → LRN`，黄金三角只改变研究对象如何被理解和组织，不绕过 Evidence、Falsifier、Replay 或 Outcome。

## 2. P｜Paradigm Potential · 范式势能

### 2.1 定义

P 不是“康波拐点预测器”。它把 Kondratieff/Perez 一类长波研究退回到**解释性结构框架**：判断某项技术或产业是否正在成为下一代生产函数、基础设施或制度安排的一部分。

### 2.2 六类观察面

1. **技术突破**：关键能力是否跨越可用阈值；
2. **成本曲线**：单位成本是否持续下降并打开新需求；
3. **基础设施**：配套网络、算力、能源、供应链是否形成；
4. **资本形成**：资本开支与融资是否从试验转向系统性建设；
5. **制度适配**：监管、标准、组织与商业制度是否开始重构；
6. **生产率扩散**：是否从局部演示走向跨行业生产率或单位经济改善。

### 2.3 阶段语言

P 的阶段建议采用 Perez 式结构语言，而不绑定固定年份：

`emergence → installation → frenzy → turning_point → deployment → maturity → unknown`

### 2.4 禁止事项

- 禁止根据“约 50–60 年周期”推算具体年份；
- 禁止把历史类比当作因果证明；
- 禁止因为叙事崩盘自动宣布范式终结；
- 禁止用一个 P 分数替代对六类结构证据的逐项审计。

## 3. N｜Narrative Momentum · 叙事动能

### 3.1 定义

N 沿用 Shiller 叙事经济学与现有 `Narrative → Observation → StageSnapshot` 正本：研究一个故事如何从少数传播者扩散到更多资金、企业、媒体与用户，再因拥挤、证伪或遗忘衰减。

### 3.2 状态

现有阶段扩展为：

`discover → accelerate → consensus → decay → residual → unknown`

其中 `residual` 表示主叙事热度退潮后仍被真实需求、现金流或幸存者持续承载的残留期；它不等于重新加速。

### 3.3 关键观测

- 传播代理：提及率、搜索、融资/IPO 密度、用户采用、叙事企业家传播；
- 遗忘/反向代理：反向叙事、证伪事件、融资收紧、边际传播收益下降；
- **ΔN**：叙事速度；
- **Δ²N**：叙事加速度；
- crowding：共识拥挤；
- novelty：信息新颖度；
- carrier diversity：传播载体多样性。

### 3.4 核心纪律

- `I(t) ≠ R∞`：当前热度不等于最终影响；
- 传播力不证明商业正确；
- 叙事见顶不需要外部利空，拥挤本身可以导致衰减；
- 反向叙事与基本面兑现必须独立取证。

## 4. X｜Extreme Convexity · 极值凸性

### 4.1 定义

X 不是单纯 Tail Risk，也不是 VaR/ES 的别名。它同时研究：

**右尾：若范式成立，谁能获得不成比例的价值捕获？**

以及：

**左尾：若判断错误，这个对象是否会发生永久性资本损失、稀释、融资断裂或制度性归零？**

### 4.2 右尾结构

- winner-take-most / winner-take-all；
- 网络效应与生态锁定；
- 规模经济与边际成本下降；
- 标准、平台、瓶颈节点控制；
- 稀缺数据、算力、能源、牌照或渠道；
- TAM 扩张与新市场生成；
- optionality：现有业务持续生成新业务选择权；
- value capture：产业价值增长是否真正落到该实体。

### 4.3 左尾结构

- 资产负债表与流动性；
- 高杠杆与再融资依赖；
- 永久稀释风险；
- 单一客户/供应商/政策依赖；
- 技术替代；
- 监管或许可归零；
- 估值压缩与现金流错配；
- EVT / POT-GPD / VaR / ES 等尾险测量作为**风险插件**，而非 X 全部。

### 4.4 原则

目标不是提高“每一次都判断正确”的命中率，而是研究能否形成：

**右尾足够大，左尾不致命。**

## 5. 基本面不是第四个角

黄金三角保持三角，不继续膨胀成十维评分表。

- **P/N/X**：发现值得高强度研究的候选机会；
- **Fundamental Gate**：证明产业链、订单、收入、利润、现金流与治理证据没有与叙事脱节；
- **Survival Gate**：证明左尾风险没有使研究对象在验证期内先失去生存资格；
- **Valuation Context**：描述当前价格已经隐含了多少乐观假设；当前版本不输出目标价、买卖或仓位。

约束：`Fundamental Gate` 与 `Survival Gate` 任一为 `failed` 时，不得仅凭 P/N/X 的强势将对象分类为高研究优先级。

## 6. Force Triangle 研究物种

第一版采用可解释分类而非总分：

| P | N | X | classification | 含义 |
|---|---|---|---|---|
| strong | accelerate | convex | `golden_extreme` | 范式、传播和右尾结构同时强，进入最高研究优先级候选 |
| strong | discover/residual | convex | `latent_dragon` | 范式与极值成立，但共识尚弱或已退潮，适合长期追踪验证 |
| strong | consensus/decay | fragile | `paradigm_bubble` | 技术方向可能成立，但价格/资本结构或价值捕获脆弱 |
| weak | accelerate/consensus | convex | `meme_extreme` | 叙事极强但缺长期范式支撑，只作为叙事现象研究 |
| weak | weak/unknown | weak | `ordinary_asset` | 缺少三角共振，不投入高强度研究资源 |
| any | unknown | any | `unknown` | 数据覆盖不足，不猜测 |

分类是**研究资源分配**，不是投资建议、交易信号或准入结论。

## 7. 标准研究链

每个黄金三角对象按以下顺序：

1. **Paradigm Map**：先建立长期结构，不从股票代码起步；
2. **Narrative Map**：识别技术事实、叙事企业家、napkin moment、传播载体与反向叙事；
3. **Convexity Profile**：分开右尾价值捕获与左尾生存；
4. **Fundamental / Survival Gates**：产业映射和公司事实验证；
5. **ForceTriangleSnapshot**：形成阶段性分类与证伪条件；
6. **Point-in-time Replay**：严格冻结 T0，只使用当时可知证据；
7. **Outcome**：分别记录市场、经营与结构验证，不以价格单一裁决理论；
8. **LearningCandidate**：错误只进入待审学习提案，不自动改 Canon。

## 8. 历史校准首批 Gold Replay

首批只做三个技术时代，用于检验方法是否能在事前信息约束下区分“范式正确”和“资产正确”：

- PC 互联网：Netscape / Cisco / Amazon 等原型；
- 移动互联网：iPhone / App Store / Facebook 等原型；
- AI：ChatGPT / 算力基础设施 / 应用层等原型。

核心问题不是“AI 究竟等于 1999 还是 2007”，而是分别判断不同赛道、不同实体在 P/N/X 三个维度上的状态。

## 9. 研究与生产边界

当前版本：`candidate`。

它可以：

- 形成方法论文本；
- 定义 Schema；
- 生成 `candidate/partial` 研究对象；
- 做 point-in-time Replay；
- 在 `yuanli-invest-rsi` 中作为 challenger 做 Shadow 评测。

它不可以：

- 绕过 Evidence Reviewer 将对象升级为 `approved`；
- 自动改变 A9 operational canon；
- 自动修改 `yuanli-invest-rsi` FROZEN 规则；
- 输出个性化买卖、仓位、目标价或收益承诺；
- 因历史回放表现好而自我晋级为生产规则。

## 10. 理论血缘与当前证据基座

- Robert J. Shiller：Narrative Economics / SIR 叙事传播；
- Carlota Perez：技术革命的 installation / turning point / deployment 解释框架；
- 本仓 `docs/methodology/叙事投研方法手册.md`：Narrative、Observation、StageSnapshot、AssetMapping、Thesis、Replay 的现有研究协议；
- 本仓 `docs/methodology/AI标的物叙事经济学深研报告.md`：PC 互联网、移动互联网、AI 三轮叙事与资产映射的现有研究基线；
- Evidence Vault：长波范式与叙事经济学双坐标研究、三轮周期智库、尾部因果/极值研究材料。原始 PDF/XLSX 不进入 GitHub。
