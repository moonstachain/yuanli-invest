# 原力投研工程审查与简化

审查基线：GitHub `moonstachain/yuanli-invest` 的 `705dbed`。日期：2026-09-24。范围涵盖产品入口、功能调用链、研究算法、数据契约、持久化、运行错误处理、性能与 CI。本轮没有连接真实 Wind、修改生产数据库、启动调度或覆盖历史研究回执。

## 核心判断

复杂度主要来自历史流程和未来架构占据当前使用接口，而非 Python 类层次过多。代码能够做黄金观察与研究实验，但首页要求读者先理解战役、权限、正典和平面；部分测试冻结了架构层数和术语，却没有发现真实的计算与落盘错误。

最小产品应直接回答：今天观察到什么、较上次如何变化、依据是什么、仍不知道什么、何时验证判断。当前规模用一个 Python 工程、数据/研究/记录/呈现四项职责即可。没有性能证据支持增加微服务、消息总线、通用插件框架或全局缓存。

“最高性能”不是可证明的绝对目标。本轮采用相同输入、输出等价和可复现实测作为依据，优先减少重复进程、扫描和等待。

## 什么是过度防御，什么应该保留

可去掉的是同一可信输入在嵌套函数中重复验证、同一门禁在一条 CI 路径重复运行、没有实际语义的转发函数、重复读写和异常分支，以及把历史交接当作永久操作手册。本轮直接处理了这些运行和入口问题。

应保留的是外部数据格式与时间、引用完整性、凭据边界、研究与交易执行区分、结果可追溯、写入原子性、历史实验窗口和预注册判断的可复核性。这些检查保护真实的不变量，不能因为“减少防御”而删除。

输入错误检查集中在公开入口。独立公开调用的 build_state_delta/build_settlement 仍验证自己的输入；build_learning_candidate 验证一次后直接调用内部计算。此处两种调用方式确实存在，不能删掉独立接口的输入检查。

## 测试依据

基线 283 项测试全部通过，耗时 10.307 秒；最终 316 项测试全部通过，耗时 2.273 秒。新增覆盖重点是原先漏掉的行为：稳定状态分类、前值时间排序、有限数、指标日期穿越、完整的离线 CLI、损坏可选学习文件、并发回执写入、原子替换失败、当前学习关联、学习失败退出码、Git 原始二进制与特殊文件名、日期和 URI 格式、索引查询结果等价。

CLI 真实子进程验收覆盖状态和比较；旧 Live Shadow 的直接脚本和 `-m` 两种入口均通过本地 Node stub 验收。全部验证为离线测试；未把模拟供应商成功当作生产服务可用的证明。

CI 去重对应：repository→test_contracts；gold_reconstruction→test_gold_reconstruction；qxm2_evidence_hardening、yip0、me0、yvn1、yim0、yios0、四项 yios_g1、yks0_r0 均由各自测试调用完整验证函数。只有部分断言覆盖的 ME1、YEX0、QXM2 post-merge 等仍保留独立门禁。contracts/governance 名称不变。

## 架构设计与尚未解决的实质问题

目标职责和现有代码映射见 [ARCHITECTURE](../../ARCHITECTURE.md)。本轮已经把存储与呈现单独收敛，保留老脚本入口，避免一次移动所有文件破坏已有调度和调用方。

下列问题不能用性能重构自动解决，仍明确保留：

1. **完整到期结算。** 当前只比较观察变化，不能给没有预注册判断的历史数据补造胜率。下一功能应定义判断时间、证据、条件、到期日与结果，并用真实样本端到端验收。
2. **固定实验输入与持续面板冲突。** B2 锁定 584 月/2,336 行至 2026-08；backfill 会延长同名面板。应让冻结实验引用不可变快照或显式窗口，不能直接延长旧实验并沿用旧结论。
3. **历史校验与运行校验分层。** 仍有精确检查 13 层/8 服务/源码词语的历史 gates。它们能证明资料未被改写，无法证明功能存在。本轮只删除重复执行；后续应迁为归档一致性检查，并用真实业务契约替代当前源码词语冻结。
4. **原始历史数据缓存与恢复。** backfill 逐月 CPI 请求仍有网络和限速成本。应按 series/as_of 复用不可变响应、补齐缺失月份；本轮没有改供应商交互或重新抓数据。
5. **时间与数据质量语义。** 部分月度面板是重建/代理数据，“字段未穿越”不等于历史 vintage 可交易证明。compiler 的日期切片仍兼容既有日期/时间字符串；严格粒度应与契约一起整理。
6. **完整安装与产品层。** 本轮提供仓库根目录的离线 CLI 和测试安装方式；历史 backfill 的 openpyxl/boto3 等能力依赖、正式包安装、Web 产品不是已经完成的能力。先围绕实际使用者补齐它们，不按未来服务数量扩张。

本轮没有修改研究授权配置、历史数据、数据库迁移或生产调度。算法错误修复会影响未来新运行的分类；旧结果不自动回写。所有变化通过独立分支提交评审。
