# YMA55 2.1｜Kernel Closure & Phase-2 Transition

**Status:** `transition_candidate_pending_h4_3_human_acceptance`  
**Date:** 2026-08-24  
**Purpose:** stop default theory expansion after H4.3 and move the program from epistemic-kernel invention to evidence, shadow exposure and reality settlement.  
**Phase-2 execution authority:** none

## 1. Closure thesis

YMA55 2.1 is considered research-kernel complete only if H4.3 receives 24/24 Human Review and explicit acceptance.

The kernel is not defined by the number of historical cases. It is defined by three machine disciplines:

> **没有证据，可以不知道。**  
> No sufficient evidence → no forced resolution.

> **有喜欢的解释，也必须允许它输。**  
> Primary is a contestant; Alternative / Null can win.

> **历史上是对的，也不代表今天有资格说话。**  
> Historical validity must earn transfer authority and can later be revoked by current evidence.

These compile into:

```text
Evidence
→ Causal Compression
→ Competing Mechanisms
→ Transferability
→ Prior Violation
→ Reality Settlement
```

## 2. Theory Freeze Rule

After H4.3 Human Acceptance:

`DEFAULT_THEORY_EXPANSION = FROZEN`

There is no default H4.4 theory battle.

A new theory/ontology battle may be opened only when a documented failure survives all three lower-level explanations:

1. **Evidence failure ruled out** — the issue is not missing, low-authority, non-independent or future-leaking evidence.
2. **Implementation failure ruled out** — the issue is not a bug, schema mismatch, resolver drift or runtime leakage.
3. **Challenge-design failure ruled out** — the issue is not an ambiguous settlement, poor control pair or invalid transport mapping.

Only then may a `THEORY_CHANGE_REQUEST` be proposed, with:

- failure record;
- affected invariant;
- minimum semantic change;
- hard negative;
- replay migration impact;
- backward-compatibility assessment;
- Human Gate.

Framework elegance alone is not a valid reason to reopen theory.

## 3. Phase-2 objective

Phase 1 asked:

> Can we build a historical-prior system that is difficult to fool with hindsight, preferred stories and naive historical analogy?

Phase 2 asks:

> Can the frozen kernel operate on higher-authority evidence, survive a current-world shadow stream, and improve through repeated Reality Settlement without gaining unauthorized capital power?

The phase changes from **model invention** to **epistemic operations**.

## 4. Phase-2 architecture

```text
YMA55-EH0｜Evidence Authority Hardening
            ↓
YMA55-SR0｜Current-World Shadow Runtime
            ↓
YMA55-RS0｜Reality Settlement & Prior Update
```

No stage may be skipped.

## 5. YMA55-EH0｜Evidence Authority Hardening

### Goal

Upgrade the authority of the evidence feeding historical priors and transferability assessments before introducing a live/current shadow stream.

### Primary scope

1. Hydrate the five transferability dimensions with explicit evidence lineage:
   - monetary regime;
   - fiscal capacity;
   - market structure;
   - global order;
   - policy toolkit.
2. Separate:
   - primary contemporary evidence;
   - independent contemporary evidence;
   - PIT-derived evidence;
   - later reconstruction;
   - retrospective narrative.
3. Preserve explicit `UNKNOWN` where evidence is insufficient.
4. Verify source independence rather than counting two copies of one information chain as two sources.
5. Add source freshness / known-at / evidence-cutoff rules for current-world ingestion.
6. Upgrade only evidence authority; do not change H1/H2/H3 semantics by default.

### Required machine output

`EvidenceAuthorityPack` containing at minimum:

- object_ref;
- as_of / known_at;
- source_class;
- independence_group;
- authority_grade;
- admitted / rejected;
- rejection_reason;
- observable / claim relation;
- missing_evidence;
- future_leakage=false.

### Gate

`EH0_PASS` requires evidence-lineage integrity, independence integrity and fail-closed UNKNOWN handling.

It does not authorize Historical Gold admission unless a separate Human Gate explicitly does so.

## 6. YMA55-SR0｜Current-World Shadow Runtime

### Goal

Expose the frozen kernel to current-world evidence without giving it capital authority.

### Runtime separation

```text
Historical Prior Vault
        ↓ one-way compile
Historical Prior Pack
        +
Current Evidence Snapshot
        ↓
Posterior Research State
        +
Market Clock Timing State
        ↓
Shadow Research Output
```

### Core rules

- Historical replay artifacts remain immutable from current evidence.
- Current evidence cannot rewrite historical Gold/Hard-Negative settlement.
- H3 transferability is evaluated before a historical prior receives current authority.
- Prior Violation is evaluated only after transfer authority is earned.
- Market Clock supplies timing/sensing, not historical truth.
- `Research PASS != Capital PASS`.
- Shadow output contains no position size, trade action or live-execution instruction.

### Initial shadow universe

Keep the first shadow deliberately small and cross-asset:

- Equity representative;
- UST30Y;
- Gold;
- Copper;
- USDJPY.

The purpose is not portfolio optimization. The purpose is to expose whether the same historical mechanism behaves coherently across different market sensors.

### Minimum shadow output

For each observation date:

- current WORLD state;
- binding CONSTRAINT candidate(s);
- active TRANSMISSION channels;
- Primary / Alternative / Null mechanism set;
- supporting and contradictory historical priors;
- transferability state;
- prior-violation state;
- Market Clock state;
- uncertainty / abstention state;
- falsifier / breaker;
- no-capital-authority flag.

### Gate

`SR0_PASS` requires a fixed shadow horizon with zero capital-authority leaks, no historical rewrite, complete PIT timestamps, and a stable audit trail.

## 7. YMA55-RS0｜Reality Settlement & Prior Update

### Goal

Make reality, not narrative coherence, the recurring final authority.

### Settlement classes

Every matured shadow thesis must settle into one of:

- `RIGHT_MECHANISM_RIGHT_OUTCOME`
- `RIGHT_MECHANISM_WRONG_EXPRESSION`
- `WRONG_MECHANISM_LUCKY_OUTCOME`
- `WRONG_MECHANISM_WRONG_OUTCOME`
- `UNRESOLVED`

Outcome direction alone cannot overwrite mechanism settlement.

### Prior-update rule

Reality Settlement may propose:

- maintain prior;
- downgrade prior;
- reopen mechanism competition;
- retire current prior application;
- request new evidence;
- propose theory-change review.

It may not silently rewrite historical episodes or Canon.

All durable prior changes require an auditable update ledger and Human Gate.

### Gate

`RS0_PASS` requires repeated settlements with preserved wrong-mechanism/lucky-outcome distinctions, no hindsight rewrite and no unauthorized capital action.

## 8. Phase-2 success metric

The program should not optimize report count, historical-case count or narrative richness.

Primary objective:

`Epistemic Error Reduction under Reality Settlement`

Track at least:

- forced-resolution rate when evidence is insufficient;
- preferred-primary survival rate after Alternative / Null competition;
- unsafe historical-prior transport count;
- prior violations detected / missed;
- wrong-mechanism lucky-outcome count;
- time-to-falsification;
- silent thesis migration count;
- evidence-authority violations;
- capital-authority leaks.

A lower forced-resolution rate or faster falsification may be an improvement even when directional hit rate does not rise.

## 9. PR and governance strategy

H4.3 is the intended endpoint of Draft PR #57's methodology-hardening program.

After H4.3 Human Acceptance:

1. perform a dedicated PR #57 Strategic Merge Review;
2. do not add EH0/SR0/RS0 implementation into PR #57;
3. Merge requires separate explicit authority;
4. Phase 2 should begin on a clean branch / clean PR after the prior program is settled;
5. Phase-2 implementation itself requires explicit user authorization.

This avoids turning PR #57 into a permanent program branch and preserves reviewability and causal attribution of regressions.

## 10. Phase-2 stop conditions

Stop and request Human Review if any of the following occurs:

- current evidence mutates historical settlement;
- transferability becomes a scalar score that can override blockers;
- Alternative / Null are removed or made non-competitive;
- UNKNOWN is coerced into a directional answer;
- Prior Violation emits a trade action;
- Market Clock gains historical truth authority;
- Portfolio/position sizing enters YMA55 runtime;
- a theory change is proposed without a settled failure record;
- live execution is introduced.
