## What R0A proved

R0A proved that several evidence lanes are structurally viable:

1. U.S. macro vintages can use ALFRED-style real-time histories.
2. SEC EDGAR can provide dated corporate disclosures back to the mid-1990s.
3. Federal Reserve official material supplies strong policy/crisis anchors.
4. GDELT 2.0 supplies rights-clean open metadata from 2015-02-19 onward with high-frequency publication/mention timing.
5. Dated CSRC/PBOC/NBS pages demonstrate that Chinese contemporaneous official releases can be recovered for selected historical points.
6. Commercial providers exist that plausibly address historical Story gaps, but no provider contract has yet been admitted into the Yuanli evidence runtime.

R0A also proved that several shortcuts are invalid:

- public readability is not a storage/text-mining licence;
- SEC filings alone do not establish broad public Narrative diffusion;
- GDELT 1.0 events are not a substitute for a multi-publisher Story corpus;
- Google Trends is an attention proxy rather than Narrative truth;
- present-day revised macro series cannot silently replace historical vintages;
- a plausible source path is not the same as measured weekly coverage.

## Remediation priorities

### P0｜Historical English multi-publisher corpus

A named commercial/archive provider must be contractually audited for C1/C2. Current candidates include Nexis Data+ and ProQuest TDM Studio, but neither is admitted by this run:

- Nexis Data+ publicly advertises licensed historical news, APIs/bulk delivery, analytics and investment-insight use cases; exact customer contract, archive coverage and downstream rights are still required.
- ProQuest TDM Studio offers rights-cleared historical-news TDM, but its public supplemental terms constrain export/commercial use; it cannot be assumed compatible with Yuanli's intended commercial/internal investment workflow without a specific contract.

### P0｜Historical Chinese multi-publisher corpus

C3 requires lawful coverage from 2014-07-01 through at least 2015-02-18, preferably the full case. Wisers is a credible candidate because it publicly describes licensed Chinese-media coverage, historical data and API integration. Exact historical source coverage and contract rights must be physically audited before admission.

### P1｜China vintage reconstruction

Build a China-ALFRED-like release ledger for the exact C3 control variables: original dated release, available-at, revision/vintage relationship and immutable snapshot/hash. Selected PBOC/NBS dated releases show feasibility but do not yet constitute a complete vintage panel.

### P1｜Modern weekly coverage compilation

C4–C6 should be the first low-cost remediation experiment. Run the frozen weekly corpus compiler over admitted GDELT 2.0 metadata and topic definitions. If any case cannot clear the fixed 95%/80%/10-doc/70% thresholds, keep it limited instead of changing thresholds.

### P2｜Market-data provider binding

Although market prices are not the current bottleneck, the final `READY` state still requires a named, rights-bounded, reproducible cross-asset market-data source. This run deliberately does not infer that contract from the user's statement that market data is easy.
