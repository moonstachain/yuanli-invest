# R0｜Research Capability Canon Human Review Card v0.1

## Review purpose

本轮只裁决项目中心目标与长期资产本体，不裁决收益表现，也不改变 Q1/A6/M1.2 当前状态。

## 必审七题

### 1. GitHub 的长期中心使命是否应改为 Research Capability Canon？

接受标准：GitHub 主要沉淀理论、假说、因子、算法、Benchmark、Skill、Schema、Reference Implementation 与版本治理，而不是复制完整 Market Data Runtime。

### 2. ResearchCapability 是否应成为长期中心对象？

接受标准：股票/资产是 runtime target；可复用研究能力才是长期 Canon 资产。

### 3. Runtime 法权是否清楚？

目标：

- GitHub = Research Capability Canon
- Wind AI = Market Reality Runtime
- Codex = Research Engineering Runtime
- quant-workspace = Reference Quant Runtime
- Evidence Vault = Audit / Replay Evidence Layer

### 4. 是否接受 provider-neutral Canonical Data Field？

拒绝条件：算法核心语义继续直接绑定单一 vendor 字段。

### 5. 是否接受新的主价值链？

```text
Theory → Mechanism → Hypothesis → Factor → Algorithm → Benchmark → Skill
```

### 6. 是否接受 Q1/A6 的战略降权但非删除？

- Q1：Provider Integration Qualification
- A6：Audit / Replay Evidence Lane

它们继续有价值，但不阻塞 Capability Canon 建设。

### 7. 是否接受 PNX-S 成为 Capability Ontology？

PNX-S 用于组织和约束能力域，不生成单一 scalar PNX score。

## Explicit non-decisions

R0 接受不等于：

- 自动更新 README 正式 Mission；
- 自动关闭、merge 或 supersede Q1/A6/M1.2；
- 自动迁移 production schemas；
- 自动注册任何 Capability 为 Canon；
- 自动改变 A9 operational canon；
- 自动修改 RSI FROZEN；
- 自动授权市场执行行为。
