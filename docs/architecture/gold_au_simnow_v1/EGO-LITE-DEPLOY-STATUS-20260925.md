## API / CLI 与连接后的部署次序

优宽的扩展 API 是账户控制面：`GetPlatformList` 返回**本账户已添加的交易所**，`GetRobotList` / `GetRobotDetail` 返回机器人及绑定，`CommandRobot` 向运行中的机器人送交互字符串；策略内部用 `GetCommand()` 接收。`GetExchangeList` 只列平台**支持的协议及配置模板**，不能证明某个 SimNow 账号已添加。API 的发送成功也不代表 CTP 接受订单或 SimNow 成交。只应为专用密钥开实际所需的函数权限，验证后由本地网关发送已签名、一次性、有限时的 ActionContract。不得使用含 `SecretKey` 的 URL 作为默认传输方式。

`robot` CLI 是**托管者执行引擎**，不是替代交易连接的下单 CLI。自有主机路径可先用 `./robot -v` 核版本、`./robot -l` 核支持的交易接口，再用 `./robot -s node.youquant.com/<本人UID>` 启动，交互式输入平台密码；不要把 `-p <密码>` 放进命令历史。一键租用路径由优宽部署托管者、另行计费；官网说明这种主机不支持远程登录。官方 Python 自定义模块方式是将模块置于托管者的 `logs/storage/<实盘ID>/`，故现有多文件源码**不能直接假定**可装入一键租用主机。要坚持云托管，应先构建并审查可运行的单文件策略与 bootstrap，并在宿主验证 Python 版本和导入方式；另一条路径是经批准的自有长期在线主机。

[优宽远程编辑](https://www.youquant.com/user-guide/%E8%BF%9C%E7%A8%8B%E7%BC%96%E8%BE%91)可通过现有策略专属同步 token，把本地编辑器中的**策略源码**同步到网站；它比大段浏览器粘贴更适合正式代码交付。同步 token 具有写策略能力，应单独保管，使用前验证目标策略与同步后的源码哈希。官方没有把它描述为一键云主机的 Python 包上传接口，因此仍须解决单文件入口或经验证的模块装载路径。

实际次序：用户在官方 SimNow 页面开通／登录 → 用户在优宽添加 CTP 上期模拟第一套正常环境 → 部署专用托管者并运行独立宿主预检 → 将交易所对象**加入**机器人绑定 → 对 CTP 账户、持仓、委托做只读交叉核验 → 解决宿主 Python 3.9.2 与生产候选 3.12 门槛差异 → 创建最小权限 API Key → 联通独立时间锚、不可变账与一次性认领服务 → 先 dry-run 记录跳过／拒绝，再单独授权一手工程测试。每一步均保留实际读回，不能由上一阶段的页面选项推定下一阶段成功。

实盘页面显示一个实例大约按 `0.125 CNY/小时`计费。按页面当前价格，一个实例加上述入门主机连续 30 日约 `234 CNY`；这只是估算，未含其他实际计费或充值。现有平台余额不足以覆盖 30 日，不能据此启动长期观察。五百万元是策略**评估权益**，与优宽平台余额及 SimNow 账户资金彼此独立。

## 可交付与停止线

1. 本地生成无密钥、可校验的部署包；独立的只读 Python 宿主预检已运行，不能运行订单入口。预检仅报告解释器、必需宿主对象与模块路径规格可定位性；不能证明模块实际可导入，缺项返回 `HOST_PREFLIGHT_BLOCKED`。
2. 用户在优宽官方“添加交易所”页接手填入其 SimNow 账户凭据，核实所选为**第一套正常交易环境**。不得在对话或仓库中传送密码、授权码。
3. 账户配置和机器人绑定后，先完成独立账户、持仓、委托和 Broker ID 只读核验；宿主 Python 3.9.2 与当前 3.12 生产门槛差异须单独审查，不可直接降级交易门槛。
4. 外部时间锚、不可变事件账、跨主机一次性认领、四方对账、CommandRobot 最小权限及人工 PaperGrant 均须逐项通过；缺任何一项维持 `DENY`。消息 ACK 不算成交。
5. 一手工程测试单与后续限额内自动模拟委托是两道分开的门。任何订单提交、付款、密钥授权均不能由此页或草稿推定已经授权或发生。
