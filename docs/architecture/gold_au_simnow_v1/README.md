## 三本账

| 账本 | 回答的问题 | 证据边界 |
| --- | --- | --- |
| 历史归因 | 过去黄金变动与实际收益率、美元等观测怎样共同变化？ | 同期统计关联；不得转写为信用因果或前向交易成绩。 |
| 事前信号 | 08:30 当时哪些版本真实可用，是否满足冻结规则？ | 输入快照、规则版本、无泄漏判断、事前登记的 5/20 交易日结果。 |
| SimNow 执行与结算 | 被授权的纸面指令后来是否实际成交、持仓、结算？ | 独立 SimNow 账户读回、不可变事件账与四方对账；不由研究结果推定成交。 |

现有 G6 日更继续是**研究证据**；YVN1 合成 Shadow 只能证明其自身模拟语义，不能代替 SimNow。账户、授权、下单与真实交易之间始终有独立边界。五百万元为该策略的**评估资金账面基数**，不是现有账户资金或真实资产证明。
