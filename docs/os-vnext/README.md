The accepted Human Grammar remains the front-door research language. It is **not** replaced by the successor machine architecture.

```text
Human Research Grammar
势 · 信 · 极｜真 · 价 · 生
        ↓

P / N / E / V / S
        ↓
ME0 Return Engine Ontology
ENG-C / ENG-R / ENG-X
        ↓

ResearchTarget → EngineThesis → PositionPassport → BookState@PIT
```

Bridge invariants:

1. **Human Grammar is not Return Engine ontology.** `势 / 信 / 极｜真 / 价 / 生` remains the human research grammar; it must not be redefined as C/R/X.
2. **P/N/E/V/S are shared reusable research primitives/services.** No Return Engine owns its own private copy of Reality, Belief, Evidence, Price or Survival semantics.
3. **Asset identity does not determine permanent Engine identity.** Engine identity belongs to `EngineThesis`, so one `ResearchTarget` may host multiple independent Theses with different primary Engines and falsifiers.
4. **ME1 is a successor state model, not an in-place rewrite of history.** Historical `ResearchStateVector` identity remains preserved; future canonical write semantics use the ME1 successor object model.
5. **C/R/X is a Genesis Engine Set, not a proven exhaustive ontology.** The Engine namespace remains open-world and fail-closed under governed extension.

This bridge explains accepted architecture only. It does not create schema, Registry, portfolio, trading, execution, M3 cutover, or ME2–ME5 program authority.
