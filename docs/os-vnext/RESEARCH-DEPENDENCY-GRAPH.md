# Canonical Research Dependency Graph vNext

## Purpose

The graph preserves the accepted base OS `one_core_three_worlds_three_gates_one_loop` while adding typed cross-asset routing and authorization context.

Human semantic grammar remains:

> **P｜势 → N｜信 → X｜极｜E｜真 · V｜价 · S｜生**

Canonical X remains:

> `X := (Xs, Xa, Xp)`

Machine orchestration may be richer than the human mnemonic.

## Machine orchestration

Reference orchestration:

`A0/A1 -> L0-L4 context -> P.capital(R) + P.asset -> Xs -> V <-> N -> Xa -> Xp -> S`

with `E` attached horizontally to every material claim.

This is a **research dependency graph**, not a universal one-way causal law. Reflexivity, feedback, reverse causality and simultaneous interactions are explicitly allowed.

## P | Reality State Transition

P is the human umbrella for reality.

- `P.capital`: capital regime, discount-rate, liquidity, risk-appetite, funding and policy-reaction reality.
- `P.asset`: asset-/industry-specific physical and institutional reality.

### R | Regime Causal Decomposition

R is a typed machine decomposition/context for `P.capital`.

**R is not a fourth human world.**

Minimum state:

`growth / inflation / liquidity / risk_appetite / term_premium / funding_stress / policy_reaction_function`

Regime context may constrain downstream signal transferability or execution authorization, but it does not automatically invalidate bottom-up truth.

## L0-L4 | Cross-Asset Authority Ladder

| Level | Research object | Core question |
|---|---|---|
| L0 | Cross-Asset Regime | Where does capital prefer to go across asset classes? |
| L1 | Asset-Class Regime | Which sub-regime inside the selected asset class is active? |
| L2 | Theme / Macro-Theme Regime | Is the theme expanding, internally rotating or externally de-risking? |
| L3 | Value Pool / Market Structure | Where is value, scarcity, duration, carry or control concentrated? |
| L4 | Asset / Instrument | What is the current target state and payoff geometry? |

Invariant:

> **Lower-level truth does not imply higher-level authorization.**

Research validity and capital permission are distinct states.

## A | Two-Stage Asset / Pricing Router

A routes research physics; it is not a score or sector taxonomy.

### A0 | asset_form

`equity / sovereign_rates / credit / commodity / FX / monetary_asset / crypto / derivative`

### A1 | pricing_archetype

`growth / compounder / cyclical / duration / scarcity / event_optionality`

Invariant:

> **Asset form is not pricing model.**

A1 sets the dominant pricing engine and may set N authority to `binding`, `auxiliary` or `irrelevant`.

## Node semantics

| Node | Research object | Core question |
|---|---|---|
| P | Reality State Transition | What capital and asset-specific reality is changing? |
| Xs | Structural Asymmetry Source | Why can outcomes become disproportionately concentrated here? |
| N | Expectation Regime | Which future is the market paying for, and how is it diffusing/crowding/breaking? |
| V | Price-Implied Expectations | How much of that future is already embedded in price? |
| Xa | Conditional Tail State | Which right/left tail is being activated under current state? |
| Xp | Payoff Geometry | Does the chosen instrument capture the desired asymmetry? |
| S | Portfolio Survival | If wrong, does the system preserve the right to compound? |

### Xs specialization

The Xs mother concept is cross-asset. Example implementation families:

- equity -> value control point;
- commodity -> scarcity / supply elasticity;
- sovereign rates -> duration / convexity / term-premium asymmetry;
- credit -> default / spread / recovery / refinancing asymmetry;
- FX -> policy divergence / carry / flow;
- monetary asset -> monetary scarcity / reserve demand;
- derivatives -> volatility mispricing / convexity.

Value Control Point is therefore an equity implementation, not the universal Xs ontology.

## Canonical ordering clarification

The Seven Questions remain a human diagnostic sequence:

`P -> Xs -> N -> V -> Xa -> Xp -> S`

Runtime may evaluate V before or alongside N to compare `market-implied future` with `current expectation regime`. That orchestration flexibility does not rename N or V.

A narrative/expectation break requires bounded V/Xa/Xp re-underwriting. If the typed SLA is breached, downstream state becomes `research_only / stale`; no automatic sell action is implied.

## X semantic indivisibility

Research OS / Portfolio OS boundaries allocate **governance authority only**.

They do not remove Xp from X, redefine X as `(Xs, Xa)`, or create independent arithmetic scores.

> `X := (Xs, Xa, Xp)`

## E horizontalization

Invariant:

> `Claim Authority <= Evidence Authority`

Every material claim must remain independently inspectable through evidence metadata and falsifiers.

## State representation

Canonical machine state is a typed `ResearchStateVector` containing routing/context state and node states. No scalar Force/PNX/macro score is authoritative.

## Reflexive edges

Permitted explicit reflexive annotations include:

- price -> narrative contagion;
- narrative -> capex;
- capex -> structural reality;
- price -> financing capacity;
- financing capacity -> issuer survival;
- market stress -> correlation/liquidity;
- funding structure -> expectation duration;
- expectation break -> price -> improved/degraded V.

Any reflexive edge must be represented as a hypothesis or evidence-backed mechanism, not silently assumed.
