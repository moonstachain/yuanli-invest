# 股票叙事研究：候选 profile 与历史对照试点

这个候选包将华源材料中的“企业终局—价值捕获—价格隐含条件—重估信号”，接入原力现有研究契约，并用同一组历史案例展示输入冻结、生成研究对象、分别结算的过程。

本包有三项交付：

1. **研究规格与填写模板**：CAP-V-01 的股票叙事 profile、经营到现金流的参数桥梁、联合三情景、C/R/X 确认与失败字段。
2. **可运行的研究对象与有限反推模型**：生成既有 schema 下的 ResearchTarget、EngineThesis、能力调用、输入、结果和回执；对明确假设运行现金流敏感性格点。
3. **A/B/C/D 历史对照与结算报告**：在统一 T0 下形成预测，随后分别读取市场及经营结果，记录数值表现、数据覆盖和机制证据缺口。

**当前身份是研究候选包。** `profile_id=EQUITY-NARRATIVE-COMPARISON-v0.1`，母能力仍为 `CAP-V-01 / 0.1.0`。运行成功或案例结算不晋升全局母能力、不授予资本准入或实盘权限；候选状态和经验结论以实际生成回执为准。

## 1. 从哪里开始

从仓库根目录运行，使用能够导入 `jsonschema` 的 Python 3 环境。

### 一次运行两个阶段

```bash
python research/equity-narrative-comparison/runner.py --phase all
```

省略 `--phase` 时默认执行 `all`：

```bash
python research/equity-narrative-comparison/runner.py
```

### 分阶段检查

先准备研究对象和预测：

```bash
python research/equity-narrative-comparison/runner.py --phase prepare
```

检查生成对象、预测与冻结信息后，再结算：

```bash
python research/equity-narrative-comparison/runner.py --phase settle
```

两阶段的边界是本包的重要约束：

| 阶段 | 读取和处理 | 结果含义 |
|---|---|---|
| prepare | 只消费 T0 数值输入、候选规格、冻结规则与来源审计元数据，不读取 outcome 数值文件；生成研究对象并冻结预测 | 证明使用哪组输入、规则和假设作出了什么判断 |
| settle | 读取已冻结的 predictions 及相应 outcome，检查版本与时点后结算 | 比较原预测与实际观测，保留失败、缺失和未决 |
| all | 顺序执行 prepare 和 settle | 方便复现同一流程；不会把历史研究变成事前盲测 |

只想结算既有预测时使用 `settle`。修改协议、参数、预测或输入后，须明确创建后继版本及其冻结记录，不能在看过结果后悄悄替换原研究。这里的“冻结”是本次复现运行的规则冻结，**不是 2024 年时已经完成的预注册**。

| 现有位置 | 本包职责 |

| P.asset | 拆解需求、量价、成本、再投资、现金流和公司竞争地位 |
| P.capital | 提供利率、风险溢价、融资与流动性背景 |
| N | 保留叙事边界、传播、信念、分歧、拥挤及预期变化 |
| E | 横向约束事实、假设和结论：Claim Authority <= Evidence Authority |

| QXM1 经营驱动/现金转化候选契约 | 提供从经营数字到三表和现金流的检查方式 |
| ME0 / ME1 | 区分研究目标、收益机制、EngineThesis 与资本表达 |

本包复用 B0 的 11 个必需区块和已有 schema。P/N/V 不是所有对象共用的机械串行总闸门；E/S 横向适用。历史 `CAP-R-01` 的宏观分解身份与 `ENG-R` 分开，历史 Xs/Xa/Xp 也不被本包改名或重写。

### 同一股票的 C/R/X 需要分别判断

| EngineThesis | 核心问题 | 该试点能检查什么 |
|---|---|---|
| ENG-C | 持续价值创造、高回报再投资与多年现金流是否构成主要收益来源？ | 财务与现金流代理、短期经营兑现及缺口；单季度不能证明多年复利 |
| ENG-R | 有限期限内的信念、资金、价格、持仓与现实反馈能否产生重估？ | 原始指引、价格变化、经营兑现及独立扩散/持仓证据是否齐备 |
| ENG-X | 明确工具的尾部激活与非线性支付是否提供可实现的不对称？ | 是否具备工具、支付函数、权利金、到期、成本及触发条件 |

可以为同一目标形成多个 thesis，但每个 thesis 只有一个主要收益机制，分别保留期限、证据和失败条件。C 不以倍数必然上升作首要回报，R 不因价格上涨自动确认，X 不因股票可能涨很多自动成立。缺少某机制所需资料时，保留缺口；失效 R 不能无声变成 C，X 的期限失败不能用长期产业前景掩盖。

## 4. 如何填写经营—预期—价格研究卡

建议按以下问题阅读模板；实际状态沿既有 E/P/N/V/S 分开保存。

1. **经营现实是什么？** 先定义付费需求、产品与客户边界，连接采用/份额、量价、单位成本、经营利润。
2. **增长需要付出什么？** 加入维持与扩张资本开支、研发处理、营运资本、债务及股份稀释，形成可审计现金流桥梁。
3. **未来有哪些相互一致的条件组合？** 填写保守、基准、乐观的联合需求、份额、利润、再投资、融资和持续期。
4. **现价要求什么？** 记录可接受的折现假设下，哪些经营参数组合兼容现价；显示多解、无解和敏感性。
5. **什么证据能改变判断？** 把叙事映射到具体经营或折现条件，并同时填写确认指标、反证、截止日期与缺失规则。
6. **最终怎样结算？** 分开经营兑现、预期修订、价格表现及工具支付，回到原 thesis 而非事后重讲故事。

三套情景是联合假设：高需求、低成本、高份额与低再投资不能在没有机制支持时同时取最好值；没有校准就不赋予默认概率。**保守情景仍可能被现实突破，它不是最大损失边界。**

## 5. 当前可运行 CAP-V 的实际范围

完整 profile 包含需求、份额、利润率、资本效率等经营变量。当前 runner 使用的计算核心更有限：**给定正的基础现金流代理、增长年限、折现率及终值条件，求一个能解释观测权益价值代理的增长率，再显示不同条件组合的结果。**

对基础现金流 `F0`、过渡期增长率 `g`、年数 `n`、折现率 `r` 和终局增长率 `h`，内部算子为：

$$
F_t = F_0(1+g)^t, \quad t=1,\ldots,n
$$

$$
PV = \sum_{t=1}^{n} \frac{F_t}{(1+r)^t} + \frac{F_n(1+h)}{(r-h)(1+r)^n}
$$

终局增长从第 n 年之后开始，必须满足 `-1 < h < r`。内部现值用于条件反推，产出是增长率、终局现金流倍数、联合假设记录与识别状态，不生成目标价或上涨空间。

当前冻结的敏感性条件见 settings.json：

| 参数 | 当前取值 |
|---|---|
| 折现率 r | 8%、10%、12% |
| 过渡期 n | 5、10、15 年 |
| 终局增长率 h | 0%、2% |
| 基础现金流缩放 | 0.8、1.0、1.2 倍 |
| 过渡期增长率搜索边界 | -90% 至 200%，不在边界外强行截断为一个解 |

这些是声明的敏感性假设，尚未被估计为真实概率或校准为市场参数。格点间的解域不是统计置信区间，抽样比例也不是市场胜率。n/r/终局增长/现金流水平都保留其影响；每个条件有一个数值解，也不意味着市场预期被唯一识别。

### 现金流和股本口径

- 试点用 **经营现金流减现金资本开支** 作基础现金流代理；它没有完整处理净融资、正常化调整、股份支付和稀释，不能直接称为严格规范化 FCFE。
- 模型模块提供显式税息、营运资本和净融资桥梁。输入不足时，保留代理说明；没有实际填入的会计调整不能视为已完成。
- **年度稀释加权平均股数** 用于每股/权益价值比较的近似，不能冒充 T0 时点精确流通或摊薄股本。
- NVDA 的现有历史报价含后来拆股调整。与当时现金流/股数比较时需要明确单位转换；市场收益使用同一拆股口径。单位换算不把今日重建的数据升级为历史原始版本。
- 基础现金流非正时，当前正基数增长模型返回 `unsupported`，需要显式转型或现金流路径。它不证明公司没有价值，也不授予继续强套 PE 的理由。
- FCFF 应与 WACC 配对，FCFE 应与权益必要回报配对；持续增长要同时考虑再投资和资金成本。本次代理与有限格点不能替代完整经营—三表模型。

## 6. 历史案例与时间线

本试点使用 NVDA、AMD、INTC，市场参照为 SPY。它们是为比较机制而回顾性选择的相关行业案例，没有声称代表完整股票总体。

| 节点 | 冻结时间或日期 | 用途 |
|---|---|---|
| 统一 T0 | 2024-02-23T21:00:00Z | 三家公司共用信息截止与价格基准 |
| 过去 20 个交易日 | 以市场输入中的交易日序列定位 | 简单动量输入 |
| 后续 20 个交易日 | 2024-03-22 | 第一市场结算点 |
| 后续 60 个交易日 | 2024-05-20 | 第二市场结算点 |
| 财务结果截止 | 2024-05-31T23:59:59Z | 收集对应指引季度的经营兑现 |

**NVDA 在 2024-05-22 披露的财务结果晚于 60 交易日市场截止。** 可以把它作为独立经营结算，但不能说这份披露解释了截至 5 月 20 日已经发生的市场变化，也不能塞回 T0 或 60 日价格判断中。

三家公司财年命名不同；财务结算逐一匹配各自指引的 target period，不能因为都叫“Q1”就混为同一个期间。毛利率保留 GAAP 可比口径；缺少 GAAP 指引时记录 null 和可比较样本数，不以 non-GAAP 指引补齐。

## 7. A/B/C/D 到底比较了什么

| 版本 | 冻结规则 | 能回答的问题 |
|---|---|---|
| A：滞后财务/简单估值 | 用上一已披露季度的收入和 GAAP 毛利率维持不变作为经营预测，保留简单价格比较 | 没有新增前瞻经营信息时，简单规则会得到什么 |
| B：A 加动量 | 经营预测仍与 A 相同；过去 20 个交易日相对 SPY 为正时发出正超额预测，其余 abstain | 简单价格趋势能提供什么描述性信息 |
| C：加入经营指引与反推格点 | 经营预测取 T0 已公开的发行人收入指引中点；毛利率仅用可比 GAAP 指引；另运行条件现金流反推 | 发行人前瞻信息及有边界的 V 计算是否被正确处理 |
| D：C 加分机制证伪 | 数值预测与 C 完全相同，额外保留各 engine 所需证据、失败条件和分别结算 | 证据纪律是否阻止把数值预测正确或价格上涨误认成机制已通过 |

**发行人指引 alone 是强对照。** C/D 的经营预测与直接使用发行人指引相同，因此即使优于滞后基准 A，也只能支持“本次公开指引提供了信息”这一描述。它不能证明叙事分析创造了 alpha；D 的价值在于说明证据、失败与机制条件，不能通过复述相同预测宣称数值表现又改善了一次。

本协议的动量规则仅声明正信号；没有把非正动量改写为负收益预测。两个后续窗口跟踪的是同一原始信号，不能当作独立样本。

主要结算包括：

- 经营：收入绝对百分比误差、指引区间命中、GAAP 毛利率误差百分点、可比数据覆盖；
- 市场：拆股调整后的价格变化、减去 SPY 价格变化、正动量信号覆盖率及方向命中；
- 研究：来源可得性、会计口径、机制证据、识别限制与期限缺口。

SPY 之差是基准相对价格变化，尚未剔除行业和风格风险暴露。上述市场变化**不含股息、手续费、冲击成本、融资成本或交易规则**，不能直接称为组合净收益或风险调整 alpha。

## 8. 如何读结论

这次试点可以支持的结论包括：输入与规则能否复现、契约对象是否可验证、条件格点有没有隐藏假设、三个案例的描述性预测误差，以及哪些引擎证据尚缺。

判断范围受以下事实约束：

- 样本是三只相关股票的回顾性选择，结果早已公开，存在选择与后视影响；
- 日线为今日供应商对历史价格的重建，保留获取时间与哈希，但不是当年的历史数据快照；
- 现金流和年均股数采用披露代理，估值反推存在会计与股本口径限制；
- C/D 使用现成发行人指引，不能把加入前瞻信息的改善归为独有叙事能力；
- 市场与财务结算日期不同，经营兑现、价格变化、因果机制不能互相替代；
- 单季度结果不足以验证多年 ENG-C；缺乏独立扩散/持仓证据时不能仅靠价格确认 ENG-R；缺乏合约支付证据时不能确认 ENG-X。

因此，本包不提供因果证明、样本外投资效果、已校准成功概率或资本资格证明。后续若要检验叙事增量，需另行冻结代表性样本或明确选择规则、独立原始事件、等信息强基准、完整历史版本、可测经营终点及未来结算，保留失败与退市对象。

## 9. 来源与后续使用

华源材料以书目信息、原始 PDF 的 SHA-256、页码和原创短摘要进入 [source map](sources/huayuan-source-map.json)。同一文件的重复上传不增加证据独立性；付费 PDF 和大段正文不随本包分发。

模板和 profile 可以用于新的股票研究，填写时须重新确定 as_of、源版本、现金流口径、情景依赖和 thesis 期限。历史案例只提供流程样例，不自动继承到新标的的事实判断。扩展模型、改参数或更换样本时建立明确的后继配置与回执，使过去的判断仍可复核。
