## 1. ENG-C：持续价值创造与再投资

**稳定问题：** 是否有可持续的价值创造与高回报再投资，在可接受的价格假设下通过时间积累？

| 类型 | 必答内容 | 具体指标/阈值/期限/证据 |
|---|---|---|
| 确认 | 付费需求、实际份额及客户留存支持价值池持续性 | 待填写 |
| 确认 | 企业能够保留利润；成本、认证、渠道或网络优势有独立证据 | 待填写 |
| 确认 | 经营利润、资产变化与现金流可勾稽 | 待填写 |
| 确认 | 增量资本回报、资金成本和再投资空间可解释 | 待填写 |
| 确认 | 利润到股东可分配现金流的融资/稀释桥梁完整 | 待填写 |
| 价格条件 | 现价要求怎样的多年经营路径，哪些假设尚未识别 | 待填写 |
| 反证 | 竞争优势反转、份额或客户结构不支持原来持续期 | 待填写 |
| 反证 | 新增资本回报持续不能覆盖约定资金成本 | 待填写 |
| 反证 | 现金转化依赖延迟付款、融资或一次性处置 | 待填写 |
| 反证 | 融资、债务、稀释或经营失败侵蚀原定股东价值 | 待填写 |

**期限分别填：** 经营持续期____；下次披露____；两期财报检查____；主要结算____；thesis 到期____。

**竞争解释：** 行业涨价、低基数、会计调整、一次性补贴、资金占用变化——补充____。

**结算要求：** 两个财报期是阶段证据，不能证明多年终局；ROIC 不自动等于项目全生命周期 IRR；不依赖倍数必然上升作为 C 的首要回报。

## 2. ENG-R：有限期限内的反身性重估

**稳定问题：** 信念、资金、价格、持仓和后续现实能否在明确期限内强化或打断彼此？

| 类型 | 必答内容 | 具体指标/阈值/期限/证据 |
|---|---|---|
| 确认 | 原始事件 T0 可定位，发生在观察结果之前 | 待填写 |
| 确认 | 新事实具体改变了哪项经营、终局或折现预期 | 待填写 |
| 确认 | 扩散越过多个独立来源/载体；不是复制旧信息 | 待填写 |
| 确认 | 资金、持仓、流动性与价格作为传播传感器的证据 | 待填写 |
| 确认 | 预期—融资/开支/订单—现实反馈通道 | 待填写；无通道只报告同步 |
| 价格条件 | 现价在联合条件区域中要求有多苛刻，识别限制是什么 | 待填写 |
| 反证 | 原始事实否认、关键事件延期、客户或监管反向证据 | 待填写 |
| 反证 | 传播增量来自重复报道、平台覆盖扩大或同一营销源 | 待填写 |
| 反证 | 反馈断裂，或没有新证据支持更高的终局要求 | 待填写 |
| 反证 | 到期未出现原定重估/预期变化 | 待填写 |

**期限分别填：** T0____；信号窗口____；传播窗口____；有限重估截止____；后续经营检查____。

**竞争解释：** 简单动量、共同风险溢价、行业贝塔、技术性资金、披露时差——补充____。

**结算要求：** 市场回报、预期修订、经营兑现分别记录；便宜不是时点规则，价格上涨也不单独证明机制。不能事后拼入新的叙事拯救原假说。

## 3. ENG-X：尾部激活与支付结构

**稳定问题：** 是否有明确的不对称或非线性支付结构，其激活条件、工具几何和成本主导结果？

| 类型 | 必答内容 | 具体指标/阈值/期限/证据 |
|---|---|---|
| Xa 确认 | 哪个尾部由什么条件激活，何时能验证 | 待填写 |
| Xp 确认 | 工具/合约、支付函数、行权、障碍、结算与对手条件 | 待填写 |
| 价格条件 | 权利金、隐含波动率、偏斜、期限、盈亏平衡条件 | 待填写 |
| 成本 | 时间损耗、持有/展期、融资、交易及流动性成本 | 待填写 |
| 可实现性 | 跳空、路径、提前行权/指派及结算条件如何改变支付 | 待填写 |
| 反证 | 触发条件被推翻，或其预计发生时间晚于工具到期 | 待填写 |
| 反证 | 实际支付结构无法捕获原先的尾部不对称 | 待填写 |
| 反证 | 成本、稀疏报价或合约条件突破约定边界 | 待填写 |
| S 资料 | 保证金、融资、组合集中、压力退出与左尾责任 | 待填写 |

**期限分别填：** 激活窗口____；工具到期____；融资/保证金期限____；观察____；最终结算____。

**路由要求：** 股票经营模型只是基础背景，工具价格需另用适用模型。

**结算要求：** “公司可能涨很多”、网络效应或多个经营变量交互，不独立证明 X；必须解释实际支付及获取它的成本。原文未提供的工具机制须补独立证据。
